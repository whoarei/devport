## 内容归属

产品方案回答“为谁解决什么问题、用户如何操作、结果是什么”；技术方案回答“系统如何分层、数据如何流动、边界在哪里”。协议、算法、落盘格式及故障恢复只在对应详细设计中维护，主文档保留摘要和链接。

原有总体设计、逐功能提案、实施进度、审查补丁、交互原型和历次发布说明已经合并重写，旧文件从当前目录移除。历史版本和修改过程通过 Git 历史追溯；此次整理不发布新版本，也不改变程序行为。

## 编号与更新

1. 使用 `五位编号-主题.扩展名`；00000 为索引，00001 / 00002 为长期维护的主文档。编号代表文档身份，不包含日期或版本号。
2. 修改现有行为时更新对应文档，不再追加一篇“实施进度”或按日期累加修复记录。基线日期在确认内容后更新。
3. 只有存在独立协议、算法或生命周期且无法在现有专题清楚表达时，才新增详细设计，从 00009 接续编号，同时更新本索引。
4. 实现事实以源码为核验依据，提案必须明确标记“未实现”；不把类型存在、兼容接口或模拟测试表述为完整产品功能或硬件实测。
5. 变更后检查相对链接、HTML 锚点、README、AGENTS 和源码注释引用。两份 HTML 保持无网络字体、脚本库或 CDN 依赖。
6. 发布说明在实际发版时新建 `releases/vX.Y.Z.md`，格式见 00008；它是发布记录，不再参与设计文档编号。本次不保留旧发布说明文件。
