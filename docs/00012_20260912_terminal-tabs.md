# 多标签控制台与独立交互终端

## 目标与边界

底部面板保留一个固定的「运行控制台」标签，新增多个可关闭的「终端 · 设备」标签。
脚本/命令继续使用 RunManager、RunToolbar 和运行历史。终端独立管理连接、状态、输入和屏幕，
不增加 ScriptKind，不使用 activeRunId，不保存编辑器、不上传工作区、不设置运行超时。

首期支持 SSH 和本机 WSL；不提供串口终端。Serial Shell V1 的 nonce 完成协议、端口租约和
UTF-8 上传约束不变。串口直连、分屏、会话持久化、自动重连和工作区上传入口留到后续。

## 交互

- 标签栏的「+」打开设备选择入口，默认当前设备；同一设备可打开多个独立 Shell。
- 运行控制台保留原有工具栏、任务选择和日志；终端拥有连接状态、重新连接与关闭操作。
- 切换标签、折叠、隐藏底部面板都保持终端挂载及接收输出，恢复可见时 fit/resize。
- 连接成功且标签可见时聚焦；输入只发送到该标签的 session_id。
- Ctrl+C 作为字节 0x03 交给 PTY；Ctrl+Shift+C 复制，Ctrl+Shift+V 粘贴。
- Ctrl+Tab / Ctrl+Shift+Tab 在运行控制台与终端标签间循环切换，顺序可配置为
  左右顺序或标准 MRU；MRU 在按住 Ctrl 期间冻结顺序，松开后提交最终标签
  （见 docs/00026_20260915_ctrl-tab-console-switch.md）。
- exit / Ctrl+D 按远端 Shell 规则退出；断线明确报错，画面保留，重连创建全新 Shell。
- 关闭标签会关闭会话，确认本地清理结束后移除标签。退出应用先关闭全部终端。
- 活动终端阻止应用自动升级，沿用升级读写门锁消除创建会话与安装的竞态。

## 前端结构

ConsolePanel 只管理标签和可见性，组合现有 RunConsole 与独立 TerminalPage。
独立 terminalStore 保存标签、会话身份和状态，不混入运行 store；每个 TerminalPage 保留
自己的 xterm 实例。终端不使用运行日志 reset/replay 管道，隐藏期间继续解析 ANSI 字节。
运行历史选中任务时切回运行控制台。标签通过键盘可选择，关闭按钮有独立可访问名称。

## 后端结构与接口

TerminalManager 独立于 RunManager，使用已有 DeviceStore、SSH 认证/主机密钥校验和 WSL Bridge。
接口为 open_terminal(device_id, cols, rows)、read_terminal(session_id)、
send_terminal_input、resize_terminal、close_terminal、close_all_terminals。
状态：connecting / connected / closing / exited / failed / closed。
read 返回状态、退出码、错误和 base64 原始输出，状态与输出独立，输出不做 UTF-8 解码。

Rust 边界检查设备配置、传输、会话身份、尺寸（1..4096）和输入大小。
每个会话最多积压 1 MiB 输出，每次读取最多 64 KiB；超过上限时明确失败并关闭连接，
避免静默丢失 ANSI 字节导致终端状态损坏。输入控制队列有界，满时明确拒绝。
最多保留 8 个终端标签/会话（含已退出），限制原生缓冲和 xterm 内存。
前端每个终端最多一个读取请求，在 xterm 完成写入后才请求下一批；没有未消费 IPC 堆积。

### SSH

使用 PTY + SSH shell request，让服务端选择用户的登录 Shell 和主目录。
不通过命令拼接启动，也不运行工作区包装脚本。尺寸变化发送 window-change。
只有 exit-status / exit-signal 是明确退出；无退出消息断开属于失败。
关闭使用有时限的 channel close / SSH disconnect；PTY 挂断清理由服务器负责。
无法保证清理用户主动脱离终端的 daemon/nohup/tmux 任务，不宣称远端所有进程均已终止。

### WSL

复用受校验的 wsl.exe 结构化启动参数和 Python helper，添加专用 terminal 初始化类型，
从系统账户信息选择 Shell（无配置时 /bin/sh），在主目录以交互模式启动。
不把用户、发行版或路径拼入 Shell 命令。PTY 使用 setsid + TIOCSCTTY。
终端关闭先挂断所属会话，再升级清理该会话的进程组，覆盖作业控制产生的前后台进程组；
不会停止整个发行版。只有 helper 的明确 exit 消息确认退出，EOF 为失败。

## 验证

- 前端：标签独立、并发打开、关闭/重连、输入路由、慢速写入及隐藏状态生命周期。
- Rust：输入和尺寸边界、串口拒绝、容量上限、输出字节及溢出、关闭竞态。
- 本地 POSIX/WSL helper：交互 Shell 保持 cd/变量、Ctrl+C 后继续运行、resize、exit、
  前后台作业关闭清理、EOF 失败；不要求物理设备。
- 完整 npm test / npm run build、cargo fmt --all -- --check、cargo test --offline --all-targets、git diff --check。
- SSH 真机和串口硬件未验证时明确说明；WSL 集成测试使用实际安装的发行版按需执行。

## 实施状态

设计已确定并已实现首期范围：底部多标签、独立 SSH/WSL PTY 会话、输入/resize/关闭/重连、
有界原始字节缓冲、升级与应用退出门锁，以及 SSH 模拟、WSL helper 和前端单元测试。
