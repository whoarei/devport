# DevPort v1.1.1

## 新功能

- 标题栏同时显示当前工作区与所选 SSH / WSL 设备的工作区，分别带文件夹、设备图标，并以点号分隔。设备工作区显示设备名和上次成功浏览的目录，切换设备或进入目录时同步更新。
- 新增“设置 → 顶部路径显示”，可选择短路径（目录名）或完整路径，默认使用短路径并自动保存选择；悬停始终可查看完整设备名和路径。
- 窄窗口下两侧路径分别省略，保留图标与分隔点；同步中英文设置文案及使用说明。

## 修复

- 修复 1.1.0 中 Windows 目录空白处“使用 DevPort 打开”右键菜单不显示的问题。安装或升级会清除导致入口被隐藏的旧注册项；Windows 11 可在“显示更多选项”中访问该入口。

## 验证范围

- 前端 475 项测试、TypeScript 与 Vite 生产构建通过。
- Rust 全目标 327 项测试通过，20 项环境相关测试按默认设置跳过；Rust 格式检查通过。
- 浏览器模拟工作台验收通过，覆盖短路径与完整路径切换、重载后恢复、目录导航成功及失败、设备切换、窄窗口、中英文和深浅主题。
- Windows 隔离 NSIS 安装器验收通过，覆盖升级、重复安装、卸载、菜单归属保护，以及通过真实 Windows Shell 菜单接口复现和修复目录空白处入口隐藏的问题；使用独立注册表命名空间。
- 正式安装包由 CI 构建和签名，公开前再次执行隔离安装器验收及两套更新清单校验。
- 未执行外部 SSH 设备、物理串口、USB、资源管理器真实右键点击端到端验收及 Linux/macOS 原生打包验证。

## 升级说明

- Windows 安装版可使用应用内更新，安装或升级后自动修复目录空白处右键菜单。
- 便携版下载 `DevPort_1.1.1_x64-portable.exe`。
- `latest.json`、`devport-latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 已有配置直接沿用，顶部路径显示默认采用短路径；继续保留 DevPort 1.0 的旧版数据迁移、原始数据备份与更新兼容机制。
