# Remote Runner v0.20.0

## 新功能

- 设备工作区采用精简目录选择器：单击选中目录，双击或点击行末箭头进入，保留上级目录、路径输入、刷新及打开操作。
- 工作区选择器与文件传输两侧共用目录补全。支持鼠标选择、↑↓ 切换、Tab 补全、Enter 前往及 Esc 收起；设备支持绝对路径和 `~/`，本机支持 Windows 盘符、UNC 共享及 POSIX 路径。
- 工作区文件单击以预览标签打开，再次预览会复用该位置；双击或编辑后固定标签，已有修改不会被预览替换。
- Ctrl+Tab / Ctrl+Shift+Tab 根据焦点切换编辑器或控制台标签，并沿用最近使用或顺序切换偏好。
- 运行参数改为每行一个原始参数，保留首尾空格、忽略空行；参数预览可折叠，并支持 Ctrl+Enter 运行。

## 修复

- 输入尚未完成的设备路径时不再刷新主目录列表；浏览和补全使用独立文件接口，避免干扰当前工作区的编辑会话。设备切换或路径变化后的过期响应不会覆盖新结果。
- 目录读取失败与空目录分别显示；取消未保存文件确认时，保留工作区选择窗口。
- 终端和运行控制台粘贴后保持输入焦点；异步剪贴板读取不会把内容发给已经切换的会话。
- 没有任务时隐藏任务状态行和无效的停止操作。

## 验证范围

- `npm test`：311 项通过。
- `npm run build`、`cargo fmt --all -- --check`、`git diff --check` 通过。
- `cargo test --offline --all-targets`：294 项通过，20 项需外部环境的测试按默认规则跳过。
- 使用模拟文件接口在 Edge 中验证目录选择、双击、鼠标与键盘补全、空目录/错误、过期响应、设备切换、未保存确认取消、传输路径草稿隔离，以及明暗主题和窄窗口布局；交互样例位于 `tests/directory-browser.html`。
- 未执行真实 SSH/WSL 设备、物理串口/USB、安装升级及 Linux/macOS 桌面实测。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `Remote.Runner_0.20.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 没有配置或历史参数格式迁移；原有工作区、设备配置及参数数组继续兼容。运行参数编辑框由 JSON 改为每行一个参数，无需为包含空格的参数额外添加引号。
