# Remote Runner v0.13.0

## 修复

- 将本机、SSH 和 WSL 工作区右键菜单中的“上传 / 下载”统一为“文件传输”，更准确地表达双向传输面板的用途。
- 右键空白区打开传输面板时定位工作区根目录；右键文件或目录时定位其父目录并预选该条目。仅打开面板，不会直接开始传输，另一侧已打开的目录与选择保留。

## 文档与维护

- 增加 Bug 报告、特性请求和技术改进的 GitHub Issue 模板，便于提供复现步骤、环境信息及改进目标。
- 补充工作区“文件传输”入口的使用说明，并增加 17 项回归测试，覆盖中英文、本机与设备工作区、嵌套路径、面板显示状态及断线错误。

## 验证范围

- 前端测试 205 项全部通过；TypeScript 检查、Vite 生产构建及差异空白检查通过。
- 本次运行逻辑仅涉及前端菜单入口，后端仅同步应用版本，未重新执行 Rust 测试。
- 未执行原生 Tauri 桌面交互、真实 SSH 设备、物理串口、USB 转交、WSL opt-in、其他桌面平台及安装/升级的人工验收。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以对应 Release 工作流为准。

## 升级说明

- Windows 安装版可在本版本正式公开后通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.13.0_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.12.1，无需迁移用户配置、工作区或 Python 项目环境。
