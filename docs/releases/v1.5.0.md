# DevPort v1.5.0

## 新功能

- 精简运行控制台。任务结束后，终端在输出下一行显示状态、退出码和耗时。点击重启图标可按原配置重跑，右键可选择其他运行方式。命令、解释器、工作目录和同步结果收进运行详情，Python 环境仍可在运行设置中切换。
- 精简常用面板和对话框。设备表单将本机 Shell 和串口选项收进「高级设置」，SSH 快速连接按所选认证方式显示凭据字段。远程工作区、文件传输、USB、关于和更新界面采用更紧凑的布局，文件传输限额可以按需展开。

## 修复

- SSH 在强制停止任务后继续等待退出回执，在等待超时后关闭通道。SSH 和 WSL 更准确地记录进程是否已经启动，避免在启动前失败时误保留工作区租约。
- 修复 `rr-cli` 在读取待释放租约时遇到连接中断的恢复流程。后续连接核对原租约所有者后可以重试释放。进程退出或删除结果无法确认时保留原有保护。

## 验证范围

- Windows 上通过 506 项前端测试、TypeScript 和 Vite 生产构建，以及 Rust 格式检查和离线全目标测试。SSH 停止与租约恢复使用本地测试服务验证。
- 使用 Chromium 和模拟设备验证控制台输出顺序、重跑、详情、空态布局、SSH 快速连接、传输限额和串口高级选项。真实远程设备、WSL 发行版、物理串口和 USB 留待实测。
- Windows 安装包、便携版、旧版安装迁移、签名和两套更新清单由发布工作流校验。

## 升级说明

- Windows 安装版可使用应用内更新。便携版下载 `DevPort_1.5.0_x64-portable.exe`。
- `latest.json`、`devport-latest.json` 和 `.exe.sig` 供应用内更新校验使用。
