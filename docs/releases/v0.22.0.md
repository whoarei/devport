# Remote Runner v0.22.0

## 新功能

- 编辑器扩展为 29 种语法模式及纯文本，覆盖 Python、Shell / PowerShell、JavaScript / TypeScript / JSX / TSX、C / C++ / C#、Java、Go、Rust、Lua、Ruby、PHP、SQL，以及常见配置和文档格式。
- 按文件扩展名和特殊文件名自动识别语言，支持 `Dockerfile`、`CMakeLists.txt`、`.bashrc`、`.gitconfig`、`Cargo.lock` 等；也可在状态栏手动切换，选择随文件标签保存并在重启后恢复。
- 增加代码折叠、语言相关缩进和基础补全。补全结合语言包提供的关键词、片段或局部符号与当前文档词汇，Enter 接受候选，Esc 关闭候选，Tab 保持缩进和片段导航。
- 语法包按需加载并缓存，Markdown 代码围栏支持嵌入语言高亮；切换语言保留正文、光标和撤销历史，加载失败时可继续编辑并重试。新增提示、补全框和折叠显示适配中英界面及明暗主题。
- 本次语言扩展用于编辑，不改变现有运行入口；暂未接入 LSP，不提供跨文件语义跳转、项目级重命名或类型诊断。

## 验证范围

- `npm test`：368 项通过，覆盖语言识别、全部语法模式加载、折叠与缩进、补全、异步加载竞争、前后端语言列表一致性及工作环境恢复。
- `cargo test --offline --all-targets`：299 项通过，20 项需外部环境的测试按默认规则跳过。
- `npm run build`、`cargo fmt --all -- --check`、`git diff --check` 通过。
- 使用模拟文件接口完成浏览器交互验收，检查 TSX 高亮、手动语言切换、Markdown 代码块、折叠、补全键位、中英界面和主题切换。
- 未执行真实 SSH/WSL 设备、物理串口/USB、安装升级及 Linux/macOS 桌面实测。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `Remote.Runner_0.22.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 正常升级无需迁移配置，语法包随应用提供，无需在本机或远程设备另外安装语言服务。
- 回退旧版前请先保存文件并备份工作环境；旧版不识别新增语言标识，可能无法恢复包含这些标识的工作环境快照。
