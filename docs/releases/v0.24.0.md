# Remote Runner v0.24.0

## 新功能

- 新增独立“设备工作区”侧栏，可从“视图 → 面板”启用。跟随运行控制台选中的 SSH / WSL 设备浏览目录，按设备记住上次成功浏览的路径，切换设备或重启后继续恢复；选中串口、本机 Shell 或没有有效设备时自动隐藏。
- 设备工作区支持路径输入与补全、进入上级目录、返回设备配置根目录，以及新建、重命名和删除文件或目录。目录按需展开，可刷新、重试，并定位到文件传输面板。
- 点击设备文件直接在同一编辑区打开，与本地文件和其他设备文件同时编辑；同名文件互不覆盖，同一设备上的同一文件复用已有标签。保存固定写回原设备，切换运行设备或主工作区不会改变文件来源。
- 文件标签保留类型图标，设备文件以浅色短名后缀区分来源。标签连同关闭按钮总宽度上限 240 CSS px，空间不足时优先压缩后缀并显示省略号；悬停查看完整设备名称和文件路径。
- 设备标签、未保存草稿和编辑位置随工作环境恢复；切换或关闭主工作区时保留独立设备标签。“全部保存”处理所有来源，运行工作区任务只保存属于该源工作区的文件。

## 修复与保护

- 重命名或删除设备路径时同步相关标签，删除和文件传输覆盖前保护未保存内容；继续使用文件版本冲突检测、UTF-8 / 1 MiB 编辑限制及 BOM / 换行格式保留。
- 设备连接配置变化或设备删除后保留编辑内容并拒绝向过期来源读写；设备编辑连接缓存随连接配置修订失效，防止旧标签写向变更后的连接。

## 验证范围

- Windows 本地 `npm test`：448 项前端测试通过，覆盖设备路径记忆、多来源文件打开与保存、冲突与未保存保护、目录变更、设备配置变化、工作环境恢复及设备短名消歧。
- `cargo test --offline --all-targets`：305 项通过，20 项需外部环境的测试按默认规则跳过；包含本地 SSH 测试服务，未连接真实远程设备。
- `npm run build`、`cargo fmt --all -- --check` 和 `git diff --check` 通过。
- 使用模拟接口检查深浅主题、本地与设备同名文件标签、长文件名和长设备名截断；确认标签宽度不超过 240 CSS px，未保存标记与关闭按钮保持可见。
- 未执行真实远程 SSH、WSL 发行版、物理串口 / USB、Windows 安装升级及 Linux / macOS 桌面实测。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `Remote.Runner_0.24.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 设备配置无需迁移。新版可读取旧工作环境；保存独立设备标签后，工作环境快照包含旧版本无法识别的新增字段。降级前请先保存编辑内容；旧版本不能恢复这些新增标签和草稿。
