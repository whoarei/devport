# Remote Runner v0.23.1

## 新功能

- 文件传输设备侧新增“返回设备工作区根目录”按钮，可从任意浏览目录回到所选 SSH / WSL 设备当前配置的工作区根目录，支持 `~/` 路径解析。
- 事件中心支持逐条删除及全部清理。删除设备或运行历史产生的恢复记录不再自动过期，保留到用户恢复或手动清理；清理时同步删除对应的已删除配置或历史记录及输出日志。

## 修复

- 从工作区右键打开文件传输时，先定位此次选择的来源路径，再显示面板，避免上次浏览目录抢先恢复；右键条目定位父目录并预选该条目，另一侧已打开的目标目录保持不变。
- 本机工作区子目录按本机路径分隔符拼接，兼容 Windows 盘符、UNC 共享和扩展路径，避免混用分隔符导致定位失败。
- WSL 运行说明移到管理设备弹框的“连接方式 → WSL”选项旁，悬停或聚焦查看。文案改为运行前增量同步，并明确同一 WSL 设备工作区原地运行，16 MiB / 64 MiB 限制属于运行同步。
- 事件清理失败时保留错误和记录以便重试；并发清理、恢复或同 ID 新事件不会被迟到的操作结果错误移除。

## 验证范围

- Windows 本地 `npm test`：406 项前端测试通过；`npm run build`、`cargo fmt --all -- --check` 和 `git diff --check` 通过。
- `cargo test --offline --all-targets`：301 项测试通过，20 项环境相关测试按默认设置跳过，覆盖本机模拟 SSH/SFTP、运行生命周期及终端行为。
- 浏览器模拟后端验收：本机工作区右键切换传输目录并预选文件、设备子目录返回配置根目录、WSL 提示显示及键盘收起。
- 未执行真实远程 SSH、WSL 发行版、物理串口、USB、Windows 安装升级及其他操作系统验证。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `Remote.Runner_0.23.1_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 配置格式不变，无需迁移。回收记录改为由用户手动清理；清理后无法再通过事件中心恢复对应的设备或运行历史。
