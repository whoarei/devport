# DevPort v1.2.0

## 新功能

- SSH 快速连接：输入 `[用户@]主机[:端口]` 即可打开终端和设备工作区，无需先添加设备。默认临时使用，支持密钥或密码认证，需要时一键保存为设备；最近连接仅记录地址。

- 设备管理新增“复制设备”：沿用连接和认证配置生成可编辑的新设备草稿，名称自动追加“副本”并避免重名，保存后创建独立设备，不改变原默认设备。
- 设备工作区的目录和空白处右键新增“在终端中打开”，在对应 SSH/WSL 设备的所选目录或当前浏览根新建终端，保持当前源工作区不变。
- 本机工作区和设备工作区的文件树支持直接上传、下载，保留相对目录结构；没有同名文件时预检后立即开始，仅遇到同名文件才询问保留两份、跳过或覆盖。
- 设备工作区未打开或目录尚未就绪时不开始传输，仅显示 5 秒后自动消失的提示；进度、取消、重试和传输错误继续显示在文件树中。
- 测试 SSH 连接发现主机密钥变化时，展示地址与新旧 SHA-256 指纹，由用户确认覆盖后重新连接；取消保留原记录，重连时密钥再次变化需要重新确认。

## 修复

- 新建本机终端时使用当前本机工作区作为起始目录，显式指定的终端目录仍优先，重连保留该标签的起始目录。
- 工作区脚本、预置命令和历史任务运行成功后自动展开运行页并聚焦控制台，便于继续输入。
- 侧栏面板标题和操作按钮在内容滚动时保持可见，支持左右侧栏布局。
- 编辑器普通提示改为可关闭的浮动提示并在 5 秒后自动消失；需要处理的文件冲突和读取失败继续保留操作入口。
- 工作区直接传输在预检及冲突确认期间检查两侧目录和设备是否变化，过期计划不启动；保留来源未保存确认和目标已打开文件的覆盖保护。

## 验证范围

- 前端 500 项测试、TypeScript 与 Vite 生产构建通过。
- Rust 全目标 333 项测试通过，20 项环境相关测试按默认设置跳过；Rust 格式与 Git 差异检查通过。
- SSH 快速连接验证地址解析、临时凭据不落盘、保存失败保留重试、设备身份保留，以及临时工作区/草稿/终端不进入重启恢复快照。浏览器模拟验证认证失败转密码、主机密钥取消与确认、临时连接打开工作区及终端、保存为设备后保留原终端。
- 本机 SSH 模拟服务验证主机密钥变化、确认覆盖、陈旧确认拒绝及损坏信任记录保护；确认前不发送账号密码。
- 浏览器模拟工作台验证直接上传、下载、同名文件确认与覆盖、已打开文件保护，以及设备工作区未打开时仅短暂提示并自动消失；设备工作区空白处和目录右键可在对应根目录及子目录打开并切换到新终端；设备复制草稿可编辑并保存为新设备，重复复制自动避开名称，原设备和默认设备保持不变。
- Windows 正式安装包、签名、隔离安装器验收及两套更新清单一致性由 Release CI 检查通过后公开。
- 未执行真实外部 SSH 设备、物理串口、USB、真实 WSL 发行版集成及 Linux/macOS 原生打包验证。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `DevPort_1.2.0_x64-portable.exe`。
- `latest.json`、`devport-latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 现有设备、工作环境和偏好配置直接沿用，继续保留旧版数据迁移、原始数据备份及更新兼容机制。
- 工作区直接互传以两侧已打开的工作区为目标；需要选择任意本机或设备目录时，使用文件传输面板。
