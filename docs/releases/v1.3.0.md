# DevPort v1.3.0

## 新功能

- 工作台采用圆角内容区。左侧图标栏可打开、展开或隐藏工作区、预置命令等面板，底部可直接打开设备管理。
- 运行控制台空闲时，目标设备、Python 环境和运行设置集中在底部卡片。显示任务输出时，运行设置回到输出上方。
- 默认采用暖灰浅色主题和橙色强调色。已保存的浅色、深色和跟随系统设置继续生效。

## 修复

- 窄窗口高倍率缩放时，标题栏会收紧菜单和布局按钮，为最小化、最大化和关闭按钮留出空间。

## 验证范围

- 502 项前端测试、TypeScript 检查和 Vite 生产构建通过。新版界面已在 Windows Tauri 桌面启动验证。
- 使用模拟设备检查了侧栏拖动和换边、设备管理、终端切换、浅深主题以及 200% 缩放。实体设备和 Linux/macOS 原生打包留待实测。
- Windows 安装包、便携版、签名、隔离安装流程及两套更新清单由发布工作流校验。

## 升级说明

- Windows 安装版可使用应用内更新。便携版下载 `DevPort_1.3.0_x64-portable.exe`。
- `latest.json`、`devport-latest.json` 和 `.exe.sig` 供应用内更新校验使用。
