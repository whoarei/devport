# Remote Runner v0.18.1

相对 v0.18.0，本版本精简独立终端标签，兼顾 Windows 和 Linux Shell 上报的不同标题格式。

## 修复

- Windows 终端上报完整 `.exe` 路径时，标签只显示 `pwsh` 等程序短名；Linux 的 `用户@主机:目录` 标题只显示主机和目录末级，根目录 `/` 与主目录 `~` 保留。
- SSH / WSL 标签优先保留配置的设备名，方便区分运行目标；自定义标题保留原意，带启动参数的命令标题不当作程序路径压缩。
- 去掉标签中的“终端”前缀，标题文字最多显示 180px，超出省略；状态点、编号与关闭按钮保持可见。
- 悬停提示和无障碍名称保留完整原始标题及设备名。未收到标题时继续显示设备名，重连后清除旧会话标题。

## 验证范围

- Windows 开发环境中，前端 283 项测试全部通过；TypeScript 检查、Vite 生产构建、Rust 格式检查及差异空白检查通过。
- Rust 离线全目标测试共 290 项通过，20 项 WSL opt-in 测试按默认跳过，包含本机 Shell、串口模拟和本机 SSH/SFTP 集成验证。
- 浏览器使用模拟 OSC 标题输入检查了 Windows 程序路径、Linux 用户/主机/目录、SSH / WSL 设备名及自定义长标题，确认悬停全文、标题省略、编号和关闭按钮；同时检查了中英文及明暗主题。
- 未执行原生安装/升级人工验收、外部 SSH 设备、物理串口、真实 WSL、USB 或其他桌面平台验证；模拟标题验收不等于设备实测。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以本版本 Release 工作流为准。

## 升级说明

- Windows 安装版可在本版本正式公开后通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.18.1_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.18.0，无需手动迁移配置。本次只调整标题展示，不改变终端目录、执行方式或工作环境快照格式。
