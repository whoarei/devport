# Remote Runner v0.13.1

## 修复

- 安装更新时不再要求逐个手动关闭活动终端。有活动终端时提示更新将关闭所有终端，确认后自动关闭并等待清理完成，再下载和安装更新；取消确认保留终端，清理失败则停止更新。
- 标题栏与“关于”对话框共用上述流程，并显示“正在关闭终端…”状态。确认和安装期间禁止新建或重连终端，避免关闭后又建立新会话；更新前仍保存终端标签供下次恢复。
- 活跃运行任务、文件传输及未保存编辑内容继续阻止安装更新。

## 验证范围

- 前端测试 212 项全部通过，新增 7 项回归覆盖取消确认、清理等待与失败、两个更新入口、无活动终端、确认后重新检查以及更新期间禁止终端新建与重连；TypeScript 检查、Vite 生产构建及差异空白检查通过。
- Rust 格式检查及离线全目标测试通过：280 项通过，20 项 WSL opt-in 测试按默认跳过。
- 未执行原生更新确认弹窗和安装/升级的人工验收、外部 SSH 设备、物理串口、USB 转交、真实 WSL 或其他桌面平台验证。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以对应 Release 工作流为准。

## 升级说明

- Windows 安装版可通过应用内更新升级。从 v0.13.0 升级到本版本时，旧客户端仍要求先手动关闭活动终端；自动关闭流程从 v0.13.1 生效。
- 便携版下载 `Remote.Runner_0.13.1_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.13.0，无需迁移用户配置、工作区或 Python 项目环境。
