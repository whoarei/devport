# Remote Runner v0.10.0

## 新功能

- **USB 共享到 WSL2**：新增「文件 → USB 共享」入口，管理 Windows USB 设备的共享、连接、断开、取消共享及离线记录，并检查 Linux 设备节点权限。依赖默认 Program Files 目录安装的 usbipd-win 5.x；共享操作按需请求 UAC。
- **USB 共享到远程 Linux**：选择已保存的 SSH 设备，检查远端 Python、usbip、内核模块和连接条件，再完成接入、精确断开及权限验证。USB/IP 数据通过 Linux → Windows 的 TCP 3240 直连，需可信局域网或 VPN；远端需 root 或对应命令的免密码 sudo 授权。
- **SSH / WSL 双向文件传输**：新增双栏文件传输面板，支持本机与设备之间的二进制文件、多选和递归目录复制，包含隐藏文件和空目录。支持跳过、覆盖、保留两份的冲突策略，以及预检确认、进度、取消、失败项重试和临时文件清理。单文件上限 2 GiB、单批 10 GiB、10,000 条目。
- **浏览与任务历史**：分别记忆本机和各设备上次成功打开的目录，切换设备或重启后恢复。传输历史持久保存，重试记录相互关联；成功任务自动折叠，失败和待核对任务保留，详情可查看逐文件结果及前后尝试。

## 修复

- 修复从界面启动文件传输时，后台任务缺少 Tokio 运行时上下文导致应用退出的问题。
- 修复重试成功后原中断或失败记录仍重复占据待处理列表的问题；保留原始结果以及仍需核对或清理的记录。

## 验证范围

- 前端 143 项测试、TypeScript 检查和 Vite 生产构建通过；Rust 格式检查、离线全目标测试（195 项库测试、15 项 SSH 集成测试通过，13 项环境相关库测试默认忽略）及 `git diff --check` 通过。
- 自动化覆盖 USB 状态、身份和参数校验、串口互斥、SSH / SFTP 仿真传输、路径边界、冲突策略、取消、历史恢复、重试关联和前端异步浏览。
- 实际 USB 转交、UAC、远程 Linux 的 sudo 与跨机网络仍需选定硬件联调；本次发布不操作 USB 设备。环境相关测试默认忽略，外部真实 SSH 服务端、macOS / Linux 桌面及 2 GiB 边界未实机验证。

## 升级说明

- 安装包可通过应用内「更新」按钮直接升级；便携版请到发布页下载 `Remote.Runner_0.10.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
- USB 共享依赖外部驱动和目标 Linux 环境，应用不会自动安装依赖或修改防火墙。关闭应用或结束任务不会自动断开 USB，设备拔插后暂不自动重连。
- 文件传输不支持断点续传；重启后中断任务需手动重试。提交结果标为「待核对」时，请先检查目的文件再重新选择传输。
