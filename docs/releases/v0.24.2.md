# Remote Runner v0.24.2

## 新功能

- 工作区和设备工作区的文件、目录可直接通过右键菜单上传或下载。选择目标目录并确认同名文件处理方式后开始传输，无需展开独立的文件传输面板。
- 文件、目录行背景显示传输进度，支持取消和查看详情。目录显示本批传输的总进度，展开后标识当前正在传输的子文件；成功状态保留 30 秒后自动清除，失败保留重试和清除按钮，清除状态不会删除文件。
- 文件、目录行悬停或键盘聚焦时，在右侧显示快捷操作：当前工作区的 Python / Shell 脚本可快速运行，目录可快速新建文件或文件夹，文件和目录均可上传、下载或展开“更多”。
- “更多”与右键共用完整操作菜单，支持键盘导航、Esc 关闭、焦点恢复及窗口边缘避让；菜单展开时保留所在行的高亮和操作图标。

## 修复与界面调整

- 连接配置在目标目录读取、未保存确认或传输预检期间变化时，拒绝旧操作并丢弃过期计划，保留现有未保存文件和目标覆盖保护。
- 目录传输重试仍关联原目录，成功状态到期或手动清除后不会重新显示更早的失败记录。
- 去掉工作区标题下方多余的“本机”提示；长文件名在快捷图标前省略，保持行高和按钮位置稳定。
- 取消尚在加载的菜单后，迟到的响应不会重新弹出菜单；打开“更多”不切换当前编辑文件。

## 验证范围

- Windows 本地 `npm test`：464 项前端测试通过，覆盖直接传输、连接变化、覆盖保护、30 秒状态清除、失败重试与清除、目录进度归属和行内快捷操作。
- `cargo test --offline --all-targets`：317 项通过，20 项需外部环境的测试按默认规则跳过。
- `npm run build`、`cargo fmt --all -- --check` 和 `git diff --check` 通过。
- 使用模拟设备与传输接口检查上传目标选择、冲突确认、下载重试、取消与清除、目录子文件状态、快捷运行、长文件名布局、键盘展开菜单与 Esc 焦点恢复。
- 未执行真实远程设备传输、物理串口、USB、WSL 发行版、Windows 安装升级及 Linux/macOS 桌面实测。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `Remote.Runner_0.24.2_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 工作区和设备配置无需迁移。独立文件传输面板继续可用，现有传输记录保留。
