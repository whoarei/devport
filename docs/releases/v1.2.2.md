# DevPort v1.2.2

## 新功能

- 运行工具栏新增「同步工作区」。跨设备运行直接使用上次同步的副本，每次启动只检查副本、脚本入口和运行环境。
- SSH 和 WSL 保留增量同步；串口使用最近一次完整上传的文本副本。把设备工作区同步到本机后，执行副本和产物保存在本机应用数据目录。
- 同一个 DevPort 实例内，同步完成后才能启动脚本，运行结束后才能同步。桌面应用通过任务状态管理互斥，省去远端目录锁。

## 验证范围

- 502 项前端测试、TypeScript 与 Vite 生产构建通过。Rust 格式检查及 336 项全目标测试通过，20 项环境相关测试按默认设置跳过。
- 本机 SSH 测试服务和 Ubuntu 24.04 WSL 验证了手动同步、复用副本及再次同步后执行新版。也验证了从 WSL 同步到 Windows 本机后执行，以及串口模拟器中的独立上传和副本运行。
- Windows 安装包、签名、隔离安装器和两套更新清单由 Release 工作流校验。实体串口、外部 SSH 设备及 Linux/macOS 原生打包未实测。

## 升级说明

- 跨设备运行时，目标还没有可用副本或需要更新源码时，先点「同步工作区」。已有可用的 SSH／WSL 副本可直接继续使用。同设备运行仍使用原目录。
- Windows 安装版可使用应用内更新。便携版下载 `DevPort_1.2.2_x64-portable.exe`。
- `latest.json`、`devport-latest.json` 和 `.exe.sig` 供应用内更新校验使用。
