# Remote Runner v0.11.1

## 新功能

- **SSH / WSL 工作区复用与增量同步**：同一来源工作区重复运行时，复用 `<远程工作区根目录>/<工作区目录名>/workspace`，按文件内容摘要判断变化，仅上传新增或修改的文件；只有权限变化时不重新上传内容。
- **同步结果与等待状态**：控制台展示实际执行目录、新增、更新、删除、跳过文件数及上传字节；同一远程工作区的任务排队执行，等待时可取消。

## 修复

- 同步只删除来源已移除且仍保持已知内容的受管文件，保留运行生成的日志、结果和缓存；远端源码缺失或内容变化时根据来源恢复。
- 同步使用单文件原子发布和中断恢复记录，失败时不启动脚本；工作区锁覆盖同步、环境准备和运行，避免并发任务互相覆盖。SSH 断线且无法确认进程退出时保留锁，防止后续任务覆盖仍在运行的工作区。
- 不同来源的同名工作区，以及没有身份信息的已有非空目录，会明确报冲突，避免覆盖已有数据。

## 验证范围

- 前端 174 项测试、TypeScript 检查和 Vite 生产构建通过；Rust 格式检查、离线全目标测试（265 项通过、20 项 opt-in 测试默认忽略）和 `git diff --check` 通过。
- 在本机 Ubuntu-24.04 串行执行 20 项 opt-in 集成测试，全部通过，覆盖固定目录重复运行、零内容上传、修改与删除、产物保留、权限修复、链接逃逸拒绝及排队取消。首次并行执行出现 WSL 启动超时，串行重跑通过。
- SSH / SFTP 使用本机模拟服务，覆盖同名冲突、跨设备暂存身份、中断恢复、真实内容摘要及断线遗留锁；未连接真实 SSH 设备，未执行物理串口和 macOS / Linux 桌面验证。

## 升级说明

- 安装包可通过应用内「更新」按钮升级；便携版请到发布页下载 `Remote.Runner_0.11.1_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
- 首次使用新的目录布局会重新同步一份工作区；旧 UUID 目录和旧哈希目录继续保留，不自动迁移或清理。
- 同名来源冲突时，请更改来源目录名或目标的远程工作区根目录。历史记录仍保留运行信息，但共享执行目录会随之后的同步更新，不保存每次运行的源码快照。
- 串口上传流程不变；Local Shell 和设备工作区在同设备运行时继续原地执行。
