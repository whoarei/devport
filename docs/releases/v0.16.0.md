# Remote Runner v0.16.0

## 新功能

- 右上角新增通用事件按钮，角标显示当前事件数量；展开列表可查看事件发生时间、消息和操作按钮。支持中英文和深浅主题，普通消息可单独移除。
- “文件 → 删除设备”可直接选择要删除的设备，无需进入编辑弹框，也不再弹出删除确认。删除后生成事件，可点击“撤销删除”恢复相同设备 ID 和完整连接配置。
- 删除设备事件不会自动过期，重启应用后仍可继续恢复；恢复设备保留当前默认设备，活动列表为空时将恢复的设备设为默认。

## 修复

- 编辑设备弹框的删除按钮统一采用可恢复删除；删除或恢复失败时保留设备或撤销入口，并显示错误，支持再次尝试。
- 设备配置使用同目录临时文件同步后原子替换，并串行处理修改，避免并发保存互相覆盖。列表刷新失败时保留已完成操作的结果和撤销能力。

## 验证范围

- 前端测试 221 项全部通过；TypeScript 检查、Vite 生产构建和差异空白检查通过。
- Rust 格式检查及离线全目标测试通过：284 项通过，20 项 WSL opt-in 测试按默认跳过。新增覆盖删除记录跨重启恢复、身份与凭据保留、多设备与默认设备处理、旧配置兼容、损坏配置保护和并发保存。
- 已通过模拟后端的中英文、深浅主题浏览器交互检查，覆盖菜单及编辑弹框删除、数量角标、事件时间、撤销恢复、删除记录重建、普通消息移除和键盘焦点。
- 未执行原生安装/升级验收、外部 SSH 设备、物理串口、真实 WSL、USB 或其他桌面平台验证。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以对应 Release 工作流为准。

## 升级说明

- Windows 安装版可通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.16.0_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.15.0，无需手动迁移已有设备、工作区或 Python 项目环境。被删除设备的完整配置保留在 `devices.json`，通过 `deleted_at` 标记；旧版本不识别该标记，降级后会重新显示可恢复删除的设备。
