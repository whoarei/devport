# Remote Runner v0.23.0

## 新功能

- 更新工作台视觉：统一深浅主题、文件图标、标签、控件尺寸、留白和焦点提示，增强文件树选中状态、终端文字与运行状态的辨识度。
- 编辑器、控制台和文件传输同时展开时，可分别拖动相邻面板的分隔条；支持方向键微调、Shift 加大步长，双击或 Home 恢复默认比例，并保存各面板的尺寸偏好。
- 文件与终端标签支持方向键、Home/End 导航，活动标签自动滚动到可见位置；键盘切换保留标签焦点，Enter/Space 进入内容。编辑区折叠按钮在标签溢出时保持可见。
- 预置命令增加直接运行与更多操作按钮，显示运行目标并防止启动期间重复提交，保留原有双击和右键入口。菜单及子菜单增加键盘导航与关闭后的焦点恢复。
- 运行工具栏分别展示状态、耗时和实际阶段进度；耗时包含准备阶段，任务结束后固定显示。窄窗口自动换行，面板高度不足时可滚动访问操作与输出。
- “设置 → 终端”增加 Ctrl+C 复制选区和 Ctrl+V 粘贴开关，立即应用于运行控制台及独立终端；Ctrl+C 没有选区时保留中断行为，Ctrl+Shift+C/V 继续可用。

## 修复与改进

- 同一 WSL 发行版存在多个用户或设备名称重复时，工作区与终端短标签保留足够信息，避免混淆设备。
- 文件传输分别展示未选目录、加载中、空目录和读取失败状态，读取失败提供重试入口；对齐两侧文件列表与操作区，改进进度条和错误提示的主题适配。
- 统一工作区、编辑器和控制台的空状态，减少重复的打开工作区按钮；完整路径保留在提示中，标题栏优先显示文件夹名称。
- 简化设备管理对话框：连接设置直接展开，保存与连接测试集中在底部，删除入口靠近设备名称；编辑区状态栏保留编辑信息，运行操作使用已有菜单、快捷键和控制台入口。
- 修正浏览器界面缩放时分隔条拖动距离与菜单位置的换算，避免运行面板在空间不足时裁切操作按钮。

## 验证范围

- `npm test`：385 项通过，覆盖布局迁移与相邻面板调整、设备名称消歧、标签导航与滚动、运行耗时、终端剪贴板和主题可读性等。
- `cargo test --offline --all-targets`：299 项通过，20 项需外部环境的测试按默认规则跳过。
- `npm run build`、`cargo fmt --all -- --check`、`git diff --check` 通过；工作台浏览器预览额外通过 TypeScript 检查。
- 使用模拟接口完成深浅主题、中英文、窄窗口、130% 缩放、多标签、三面板调整、菜单与标签键盘操作、预置命令防重复启动、空状态和传输失败状态的浏览器验收。
- 未执行真实 SSH/WSL 设备、物理串口/USB、安装升级及 Linux/macOS 桌面实测。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `Remote.Runner_0.23.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 本次没有不兼容的后端配置变化，正常升级无需手动迁移；已有中心布局比例自动迁移为面板尺寸偏好。
- 终端 Ctrl+C / Ctrl+V 行为可在设置中调整；现有选中即复制偏好保持独立。
