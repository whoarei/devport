# Remote Runner v0.14.0

## 新功能

- 本机工作区右键菜单新增“在系统文件管理器中打开”：右键空白区打开工作区根目录，右键文件夹打开对应子目录，支持中英文界面。
- 打开目录前沿用工作区路径校验，拒绝越界、链接、重定向和非目录目标；打开失败会在工作区错误条中提示。SSH / WSL 设备工作区不显示此入口。

## 验证范围

- 前端测试 212 项全部通过；TypeScript 检查、Vite 生产构建及差异空白检查通过。
- Rust 格式检查及离线全目标测试通过：280 项通过，20 项 WSL opt-in 测试按默认跳过。
- 未执行原生文件管理器窗口和安装/升级的人工验收、外部 SSH 设备、物理串口、USB 转交、真实 WSL 或其他桌面平台验证。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以对应 Release 工作流为准。

## 升级说明

- Windows 安装版可通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.14.0_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.13.1，无需迁移用户配置、工作区或 Python 项目环境。
