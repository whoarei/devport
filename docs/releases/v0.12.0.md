# Remote Runner v0.12.0

## 新功能

- **工作环境恢复**：重新启动后恢复当前工作区、文件标签顺序、活动文件、语言选择、光标与滚动位置、未保存草稿、目录树、终端标签、窗口位置与大小，以及文件传输面板的设备和选项。最近 10 个工作区分别记住视图，切换回来时也能恢复。
- **按需读取与草稿保护**：启动时优先读取活动文件，其余文件切换到标签时再读取；离线或文件丢失时保留标签和草稿。草稿不会自动写回源文件，来源已改变时提示冲突并保留覆盖保护。
- **亮暗主题**：通过「视图 → 主题」切换亮色、暗色或跟随系统，记住选择；编辑器、运行控制台和终端同步切换。

## 修复与优化

- **缩短运行前同步等待**：SSH / WSL 在目标设备的同步清单中保存来源文件大小、修改时间和内容摘要。来源属性未变化时复用摘要并跳过逐文件远端校验；需要检查的文件批量获取属性和摘要，SSH 启动检查与执行复用已认证连接，减少重复请求和连接。
- **同步信任策略**：属性未变的来源文件以已提交的 `manifest.json` 为准；仅在远端发生的修改或删除不会被主动发现。来源改变、删除以及中断恢复仍执行相应校验，存在恢复记录时不使用快速信任路径。
- **恢复记录可靠保存**：工作环境保存在本机应用配置目录的 `work-environment.json`，通过防抖和原子替换写入，退出及更新前刷新；损坏、不兼容或超限的旧记录保留原样并提示错误。
- 移除独立运行历史侧栏和导出入口，原有工作区脚本右键菜单中的历史命令继续可用。

## 验证范围

- 前端 188 项测试、TypeScript 检查、Vite 生产构建、Rust 格式检查和 `git diff --check` 通过。
- Rust 离线全目标测试 280 项通过，20 项可选 WSL 集成测试默认跳过。覆盖工作环境快照的读写与原子替换、草稿冲突和按需读取、同步清单信任策略、SSH 批量校验与连接复用，以及本机 shell 和模拟 SSH / 串口行为。
- 浏览器预览使用模拟存储和文件服务，验证文件、草稿、目录树、终端标签和传输选项跨刷新恢复。未连接真实 SSH 或物理串口设备；原生窗口跨显示器、DPI 切换和桌面自动启动仍需手动验证。

## 升级说明

- 安装包可通过应用内「更新」按钮升级；便携版请到发布页下载 `Remote.Runner_0.12.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
- 工作环境从此版本开始自动记录；运行控制台的任务、输出和进程不加入恢复快照。终端只恢复标签和起始目录，点击「连接」建立新会话，不重放历史命令，也不恢复旧进程。
- 恢复草稿不会自动覆盖源文件；正常退出时仍可选择保存、丢弃或取消。被强制终止时，尚未提交的约 500 ms 内修改可能未保存。
- 工作环境记录无需写入源工作区或目标设备。单个草稿及其保存前正文各限 1 MiB，完整快照限 32 MiB；超过限额会提示保存失败并保留上次成功记录。
