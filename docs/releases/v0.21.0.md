# Remote Runner v0.21.0

## 新功能

- “设备 → 管理设备…”统一添加、编辑和删除入口。在同一弹框中切换设备、修改属性、测试连接及设置默认设备；切换或关闭时可保存、放弃或取消未保存的修改。
- 设备列表支持拖拽排序，也可通过上移、下移按钮调整。顺序保存到设备 JSON，重启后保留，并同步到各处设备菜单和选择器；排序不改变当前选择、默认设备及已有连接配置。
- “设置 → 终端选中即复制”开关默认关闭，开启后同时作用于独立终端和运行控制台，并记住偏好。完成鼠标选区后复制一次，支持双击选词、三击选行和矩形选区；空选区及后台输出不会触发复制。
- Ctrl+反引号可隐藏或展开控制面板，标题栏按钮及菜单使用相同操作。隐藏后保留运行任务、终端会话、标签和分屏状态，再次展开可继续使用。

## 界面调整

- 编辑器与终端标签统一为方形标签、活动下划线和紧凑的横向滚动条，关闭按钮与标签背景保持一致。
- 事件记录的标题、时间和撤销操作放在同一行，精简删除设备后的重复说明。

## 验证范围

- `npm test`：331 项通过。
- `npm run build`、`cargo fmt --all -- --check`、`git diff --check` 通过。
- `cargo test --offline --all-targets`：298 项通过，20 项需外部环境的测试按默认规则跳过。
- 功能开发时使用模拟设备接口验证设备管理、排序及未保存修改交互；使用模拟剪贴板验证独立终端和运行控制台的选中复制行为。
- 未执行真实 SSH/WSL 设备、物理串口/USB、安装升级及 Linux/macOS 桌面实测。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `Remote.Runner_0.21.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 原有设备 JSON 继续兼容，无需迁移；设备顺序直接使用 JSON 中的数组顺序。选中即复制需在设置中手动开启。
