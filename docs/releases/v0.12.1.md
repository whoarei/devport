# Remote Runner v0.12.1

本版本为文档与发布流程维护更新，不新增运行功能，不改变用户配置或运行数据格式。

## 文档与维护

- 将分散的历史设计、实施记录及原型整理为产品方案、技术方案两份 HTML 主文档，并以六份 Markdown 详细设计和统一索引维护协议、工作区、Python 环境、文件传输、状态恢复与开发发布流程。
- 重写 README，补充软件介绍、主要功能、下载安装、首次运行示例、Python 项目环境及开发入门说明。
- 更新 README、开发指南和源码中的文档引用，移除旧文档文件；历史内容仍可通过 Git 历史追溯。
- 发布流程先展示上次稳定发布以来的更新内容、兼容性影响和版本建议，再确定版本号。

## 验证范围

- 前端测试 188 项通过，生产构建、Rust 格式检查及差异空白检查通过。
- 文档整理阶段完成 Rust 离线全目标回归：280 项通过，20 项环境相关测试默认跳过；此次发布的运行逻辑与该验证基线一致，仅同步应用版本及文档。
- HTML 主文档完成桌面和窄屏检查；文档链接、锚点及 README Python 示例检查通过。
- 本次未执行真实 SSH 设备、物理串口、USB 转交、WSL opt-in、其他桌面平台及安装/升级的人工验收。

## 升级说明

- Windows 安装版可在本版本正式公开后通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.12.1_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.12.0，无需迁移用户配置、工作区或 Python 项目环境。
