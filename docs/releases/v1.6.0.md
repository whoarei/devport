# DevPort v1.6.0

## 新功能

- 运行控制台的设备下拉框和新建终端的设备菜单会在设备列表后显示 SSH 最近连接，并用分隔线隔开。选择记录会预填地址，可继续选择认证方式。最近 10 个认证成功的地址在重启后仍可使用，记录仅包含用户名、主机和端口。

## 修复

- 选择临时 SSH 设备时，「临时连接」和「保存为设备」与设备选择器保持同一行。工具栏空间不足时，保存入口缩成带提示的图标。

## 验证范围

- Windows 上通过前端测试、TypeScript 和 Vite 生产构建，以及临时设备保存相关 Rust 测试。
- 用 Chromium 和模拟 SSH 验证中英文布局、两个连接入口、历史恢复和保存失败后重试。真实 SSH 主机留待实测。
- 发布工作流校验 Windows 安装迁移、安装包、便携版、签名和两套更新清单。

## 升级说明

- Windows 安装版可使用应用内更新。便携版下载 `DevPort_1.6.0_x64-portable.exe`。现有设备配置和项目设置可继续使用。
- `latest.json`、`devport-latest.json` 和 `.exe.sig` 供应用内更新校验使用。
