# Remote Runner v0.17.0

## 新功能

- 新增持久化运行历史面板，每次运行独立记录；默认显示当前工作区，支持查看全部工作区，进行中的任务置顶。单击可查看运行配置、状态和最多 2 MiB 的保存输出，重启后仍可查看完成记录。
- 历史记录支持按保存配置在原设备或当前设备重跑，也可先编辑入口、参数、环境、工作目录、输出模式和超时再运行。设备或来源配置发生变化时先进入编辑确认；重跑使用当前源码与项目依赖文件，并继续执行未保存修改保护。
- SSH/WSL 文件传输面板新增设备文件管理，可通过工具栏或右键菜单新建文件、目录、重命名和删除。操作受当前目录、设备配置、传输及编辑状态约束，完成后刷新目录并同步受影响的工作区视图。
- 采用新的 R 与命令箭头图标，统一应用、标题栏、托盘和关于窗口；标题栏适配 1× / 2× / 3× 屏幕。重新设计关于对话框，分组介绍功能与运行目标，集中展示更新操作，支持展开更新说明和访问 GitHub 项目主页。

## 修复

- 禁用 WebView 默认右键菜单，避免在应用中出现浏览器的返回、刷新、另存为等菜单；文件树、控制台和文件传输的自定义右键菜单继续可用。
- 修复 Windows 增量构建可能继续嵌入旧 ICO 的问题，图标资源变化会重新生成可执行文件资源。
- 关于对话框适配中英文、浅深色主题、窄窗口和界面缩放；打开时聚焦介绍区域，避免放大后直接滚动到下方按钮。下载、验证和安装期间继续阻止关闭，手动下载与错误提示分别展示。

## 文档与维护

- 更新运行历史、设备文件管理、关于对话框和图标维护说明；新增统一图标生成命令 `npm run icons` 及浏览器模拟验收样例。

## 验证范围

- 前端测试 242 项全部通过；TypeScript 检查、Vite 生产构建、Rust 格式检查及差异空白检查通过。
- Rust 离线全目标测试通过：286 项通过，20 项 WSL opt-in 测试按默认跳过，覆盖本机 Shell、串口模拟以及本机 SSH/SFTP 集成等。
- 关于对话框完成中英文、浅深色、320px 窄布局与 200% 缩放检查；通过模拟接口验证检查更新、手动下载、受阻、失败、下载进度、签名验证、安装状态与关闭保护，不执行真实安装。
- 已从重新构建的 Windows 开发版可执行文件提取图标，确认内嵌新版资源；未执行原生托盘、多显示器、安装/升级人工验收、外部 SSH 设备、物理串口、真实 WSL、USB 或其他桌面平台验证。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以对应 Release 工作流为准。

## 升级说明

- Windows 安装版可在本版本正式公开后通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.17.0_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.16.0，无需手动迁移设备、工作区或 Python 项目环境。旧历史记录缺少运行快照时仍可查看已有输出，不能直接重跑；升级后产生的记录会保存显式运行配置，包括附加环境变量，不包含设备认证信息或完整 Shell profile 环境。
- 删除运行历史会同时删除其保存输出；进行中的任务不能删除。
