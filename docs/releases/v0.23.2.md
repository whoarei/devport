# Remote Runner v0.23.2

## 修复

- 修复独立终端和运行控制台将容器内边距计入文字可用高度的问题，避免最后一行文字或光标被底部裁切；调整窗口、面板高度和界面缩放后保持完整显示。
- 鼠标点击最大化/还原、最小化、关闭到托盘及布局开关等按钮时保留原输入焦点；面板折叠、保存、直接运行/停止、刷新、关闭标签和错误提示等辅助操作采用相同规则。
- 原输入区被隐藏或关闭后，优先转到同类可见输入区，再回退到可见终端或编辑器。异步操作完成后不会抢回用户后来选择的焦点；按钮的 Tab、Enter 和空格操作，以及菜单、弹窗和标签切换的正常焦点行为继续可用。
- 编辑器使用统一的折叠箭头，鼠标移入行号区域时显示可折叠标记，已折叠标记持续可见，并同步中英文提示。
- 更新前关闭终端的确认改为跟随深浅主题的应用内对话框，显示新旧版本和活动终端数量，默认聚焦取消；取消、Escape 或关闭对话框均保留终端会话。

## 验证范围

- Windows 本地 `npm test`：407 项前端测试通过；`npm run build` 和 `git diff --check` 通过。
- 浏览器模拟后端验收：终端与运行控制台在 20 组高度/缩放组合及完整工作台标签切换、折叠/展开后无底部越界；60 项辅助按钮、焦点回退、异步鼠标/键盘切换、对话框和标签关闭检查通过。
- 未执行真实远程 SSH、WSL 发行版、物理串口、USB、Windows 安装升级及其他操作系统验证；浏览器检查不等同于原生窗口、多显示器或硬件实测。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `Remote.Runner_0.23.2_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 配置格式不变，无需迁移。
