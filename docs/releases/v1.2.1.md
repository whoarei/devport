# DevPort v1.2.1

## 修复

- 展开「设备工作区」并浏览到目标 SSH 或 WSL 目录后，点击运行按钮或双击预置命令即可在该目录执行。运行按钮提示实际路径，目录加载完成后才可启动。
- 预置命令启动时跳过文件同步和编辑器自动保存。折叠或隐藏「设备工作区」面板后，使用目标设备上已打开的主工作区，或使用目标 Shell 的默认目录。串口沿用已登录 Shell 的当前目录。
- 历史重跑在目标设备仍可使用记录中的工作区时保留该目录，跳过切换主工作区和文件同步。

## 验证范围

- 前端 502 项测试、TypeScript 与 Vite 生产构建通过。
- Rust 全目标 334 项测试通过，20 项环境相关测试按默认设置跳过。Rust 格式检查与 Git 差异检查通过。
- 浏览器模拟工作台验证运行按钮和双击在切换浏览目录后提交正确路径。本机 SSH 测试服务和 WSL Ubuntu 24.04 验证了原地执行。
- Windows 安装包、签名、隔离安装器及两套更新清单由 Release 工作流校验。实体串口、外部 SSH 设备及 Linux/macOS 原生打包未验证。

## 升级说明

- Windows 安装版可使用应用内更新。
- 便携版下载 `DevPort_1.2.1_x64-portable.exe`。
- `latest.json`、`devport-latest.json` 和 `.exe.sig` 供应用内更新校验使用。
- 现有设备、工作区、预置命令及历史记录可继续使用，无需手动迁移。
