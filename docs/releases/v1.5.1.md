# DevPort v1.5.1

## 修复

- 「管理设备」的连接测试可以随时取消。关闭弹框或按 Esc 会先停止测试，再处理未保存的设备修改。
- 每次探测最多等待 40 秒，SSH 登录后的诊断最多等待 10 秒。超时会显示提示，重新测试后只显示当前测试的结果。

## 调整

- 运行设置直接显示目标设备、Python 环境、工作目录、输出模式和超时。项目配置、环境准备和重建入口集中到「Python 环境管理」，附加环境变量、Bash 选择和写入锁恢复收进「高级设置」。

## 验证范围

- Windows 上运行了前端测试、TypeScript 和 Vite 生产构建、Rust 格式检查及离线全目标测试。
- 用本机模拟 SSH 服务验证探测卡住后的超时与断开。用 Chromium 和模拟设备验证取消、重试、迟到结果、关闭及未保存修改提示。真实远程主机、WSL 发行版和物理串口留待实测。
- 发布工作流校验 Windows 安装迁移、安装包、便携版、签名和两套更新清单。

## 升级说明

- Windows 安装版可使用应用内更新。便携版下载 `DevPort_1.5.1_x64-portable.exe`。现有设备配置和项目设置可继续使用。
- `latest.json`、`devport-latest.json` 和 `.exe.sig` 供应用内更新校验使用。
