# Remote Runner v0.11.0

## 新功能

- **工作区右键运行**：直接运行 Python / Bash 脚本、Python 模块和含 `__main__.py` 的 Python 包；入口跟随右键对象。支持逐项编辑原始参数、保存工作区历史命令、修改入口后重新运行；无参数运行始终使用空参数。
- **统一运行设置与 Python 环境**：在控制台选择目标设备、设备默认 Python 或 uv 项目环境，设置工作目录、环境变量及 PTY / pipe 模式，并查看实际解释器与启动信息。项目环境可单独准备、取消和重建，关闭设置窗口后仍可继续准备并重新查看进度与日志。
- **工作区命令与设置持久化**：命令历史和工作目录随源工作区保存，本机、SSH 和 WSL 工作区均可使用；运行上传自动排除根目录的 `.runner` 元数据。
- **控制台与设备界面改进**：精简运行工具栏和历史任务行，未打开文件时自动隐藏编辑区；优化设备配置分组与说明，点击弹窗外部不再关闭设备编辑窗口。设备默认工作区位于目标用户的主目录，已保存的自定义路径继续保留。

## 修复

- **Ctrl+C 允许程序自行处理**：运行控制台现在只发送一次中断，Python 向导捕获 `KeyboardInterrupt` 后可以返回上一级并继续运行、接收输入；键盘长按不重复发送中断。有选中文本时保留复制行为。
- **停止按钮保留分级终止**：主动停止和运行超时继续使用既有的中断、终止及强制清理流程。SSH pipe 中断等待实际进程 PID 后发送给进程组，WSL 和串口的单次中断不再启动停止倒计时。
- 修复项目环境重建可能影响活动环境的问题；重建创建独立实例，失败或取消时清理本次未发布的环境。
- 加强运行前的工作区、设备和项目输入复核，避免保存期间切换工作区或目标设备后启动错误任务；环境准备失败和进度在设置窗口中展示。

## 验证范围

- 前端 172 项测试、TypeScript 检查和 Vite 生产构建通过；Rust 格式检查、离线全目标测试（229 项库测试及 18 项 SSH / SFTP 集成测试通过，19 项环境相关库测试默认忽略）与 `git diff --check` 通过。
- 在本机 Ubuntu-24.04 显式运行 WSL 相关 25 项测试，全部通过，包含在 pipe / PTY 中捕获中断、继续输入，以及不响应中断时的停止与超时升级。
- 本机真实 Python 包回归覆盖捕获中断后等待超过原停止升级期限、继续输入和正常退出；SSH 使用 loopback 模拟服务，串口使用 Tokio duplex 和本机 Shell，覆盖单次中断、延迟 PID 标记、完成标记与停止确认。
- 未执行真实 SSH 设备、物理串口、macOS / Linux 桌面验证。Windows CPython 3.12 的 `input()` 在并行压力回归中观察到过单次终端中断触发连续 `KeyboardInterrupt` 的时序现象，详见 `docs/00024_20260913_local-shell-implementation.md`。

## 升级说明

- 安装包可通过应用内「更新」按钮直接升级；便携版请到发布页下载 `Remote.Runner_0.11.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
- 交互式向导建议使用 PTY。Windows 本机 pipe 模式不支持单次 Ctrl+C，会提示切换到 PTY 并保留任务运行；停止按钮仍可终止任务。
- 旧项目入口配置不会覆盖右键选择的脚本或模块；已有环境仍按项目的 Python 版本和依赖配置复用。普通脚本可直接使用设备默认 Python，无需先配置项目环境。
- 工作区新增 `.runner/config.json` 与 `.runner/commands.json` 保存运行目录和历史命令；已有设备的自定义工作区路径不会被默认值覆盖。
