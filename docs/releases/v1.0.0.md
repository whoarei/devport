# DevPort v1.0.0

## 新功能

- 应用正式更名为 **DevPort**：跨环境开发工作台。菜单、关于、托盘、文档和下载入口同步使用新名称，GitHub 仓库为 `whoarei/devport`。
- 使用独立的 `devport.exe`、`com.devport.app` 应用目录及 DevPort 安装、自启动身份。Windows 默认安装到 `%LOCALAPPDATA%/DevPort`。
- 首次启动自动导入 Remote Runner 的设备、历史、运行日志、工作环境、未保存草稿和界面偏好。已有 DevPort 配置优先，重复启动不会覆盖新数据。
- 安装版升级迁移原安装记录、自启动和明确属于本应用的桌面／开始菜单快捷方式；便携版首次运行也支持导入旧配置。
- 新项目配置模板使用 `[tool.devport]`，继续读取旧 `[tool.remote-runner]` 项目；两者同时存在时使用新表。

## 修复

- 更新安装识别与下载地址校验，避免更名后安装版被误判成便携版或旧客户端无法下载新版本。
- 发布新旧两套更新清单：DevPort 使用 `devport-latest.json`，旧版通过 `latest.json` 及 GitHub 重定向仍可直接升级。
- 界面偏好在语言、主题及布局初始化之前迁移，迁移失败保留原值以便重试；旧 WebView 占用存储时提示先退出旧版。

## 验证范围

- 前端 467 项测试、TypeScript 与 Vite 构建通过。
- Rust 全目标 321 项测试通过，20 项环境相关测试按默认设置跳过；格式与差异检查通过。
- Windows NSIS 安装包构建及隔离安装器实测通过：旧程序移除、新安装身份、自启动、快捷方式、未知文件保留、重复安装和卸载。
- 文件迁移测试覆盖设备、草稿、日志、界面偏好、已有新数据优先、复制失败重试和存储占用。
- 未执行真实用户完整数据覆盖升级、物理串口、USB、外部 SSH 设备及 Linux/macOS 原生打包验证。

## 升级说明

- Windows 安装版可通过原应用内更新安装；请先保存工作、停止任务并退出旧版。升级后使用 DevPort 启动。
- 便携版下载 `DevPort_1.0.0_x64-portable.exe`，退出旧版后运行新文件。
- 首次迁移保留原配置目录作为迁移前备份，新版日常运行不再读取旧目录；确认数据完整后可以自行删除备份。未保存草稿只恢复为草稿，不会自动执行或写回文件。
- 原项目无需改写；已有远端缓存及同步身份保持兼容。Windows 自启动的原禁用状态会保留。
- `latest.json`、`devport-latest.json` 和 `.exe.sig` 用于更新校验，不应单独运行。
- GitHub 旧仓库地址继续重定向，历史版本及产物保留原样。
