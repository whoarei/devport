# Remote Runner v0.19.0

相对 v0.18.1，本版本改进终端重连、历史命令管理和编辑器标签显示。

## 新功能

- SSH、WSL 和本机独立终端断开、退出或连接失败后，可聚焦终端并按 Enter 在原标签重新连接；连接失败可再次重试，仍保留按钮和右键重连入口。
- 重连保留之前的滚动输出，并添加新会话分隔线；沿用当前设备配置和标签原始工作区起始目录，不恢复旧进程、临时环境变量或后续切换的目录。

## 修复

- 历史命令统一显示全部工作区的运行记录，移除工作区筛选；没有记录时自动隐藏整个面板及分隔条，产生或恢复记录后按原布局偏好重新显示。
- 删除或清空历史命令后，记录和输出日志保留 7 天供撤销，到期自动清理；应用事件仅显示移除数量、时间和撤销入口，过期撤销事件同步移除。
- 历史清理在启动时及运行期间每分钟执行，隐藏到托盘后仍有效；清理保护活跃任务日志，写入失败保留原记录，日志删除失败会再次尝试。
- 终端重连忽略输入法确认、修饰键、长按和粘贴中的换行，触发重连的按键不会发送到新 Shell；旧会话末尾输出、标题回调和剪贴板读取不会影响新会话。
- 编辑器标签使用柔和的选中底色和 8px 顶部圆角，改善标签边缘显示。

## 文档与维护

- 同步更新终端重连、历史面板显隐及删除记录保留期限的产品和设计说明。

## 验证范围

- 前端 290 项测试全部通过，涵盖 Enter 重连、防重复、会话输出归属、真实 xterm 滚动输出保留、历史清空和过期事件刷新。
- TypeScript 检查、Vite 生产构建、Rust 格式检查和差异空白检查通过。
- Rust 离线全目标测试通过：294 项通过，20 项 WSL opt-in 测试按默认跳过；包含历史过期边界、重启清理、写入失败保留、日志删除重试、本机 Shell、串口模拟及本机 SSH/SFTP 集成验证。
- 未执行原生安装/升级人工验收、外部 SSH 设备、物理串口、真实 WSL、USB 或其他桌面平台验证。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以本版本 Release 工作流为准。

## 升级说明

- Windows 安装版可在本版本正式公开后通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.19.0_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 无需手动迁移设备、工作区或 Python 项目环境。
- 已删除的历史记录按原删除时间计算 7 天保留期限；升级后首次启动会清理此前已经到期的记录和日志。需要保留这些内容时，请在升级前恢复记录或备份应用配置目录中的 `history.json` 和 `run_logs/`。应用关闭期间到期的内容在下次启动时清理，重启不会延长撤销期限。
