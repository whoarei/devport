# Remote Runner v0.15.0

## 新功能

- 添加设备时支持四种连接方式自动命名：SSH 使用 `ssh-root@192.168.1.10:22`，串口使用 `serial-COM8:115200`，WSL 使用 `wsl-Ubuntu-24.04`（指定用户时为 `wsl-root@Ubuntu-24.04`），本机 Shell 使用 `local-pwsh`。SSH IPv6 地址会加方括号。
- 自动名称随连接信息更新；手动改名后保留自定义名称，支持“恢复自动命名”，清空名称并离开输入框也会恢复自动生成。编辑已有设备时默认保留原名称，无需重新命名。

## 修复

- 新增设备时默认聚焦连接参数：SSH 主机地址、串口、WSL 发行版或本机 Shell。切换连接方式时聚焦对应字段，名称编辑框移到连接参数之后。
- 测试连接、保存按钮可用状态和保存请求统一使用当前最终名称。

## 验证范围

- 前端测试 216 项全部通过；TypeScript 检查、Vite 生产构建及差异空白检查通过。
- 已通过模拟后端的中英文浏览器交互检查，覆盖四种连接方式的名称生成、默认焦点及切换、手动名称保护、恢复自动命名、已有设备名称保留，以及测试连接和保存使用最终名称。
- 本次未修改 Rust 运行和传输逻辑；未执行原生安装/升级验收、外部 SSH 设备、物理串口、真实 WSL 或其他桌面平台验证。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以对应 Release 工作流为准。

## 升级说明

- Windows 安装版可通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.15.0_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.14.0，无需迁移用户配置、工作区或 Python 项目环境；已有设备名称保持原样。
