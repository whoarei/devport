# Remote Runner v0.24.1

## 新功能

- 串口波特率改为明确的下拉菜单，提供 16 档常用值，并保留自定义整数输入；已有自定义数值在重新编辑时保留。
- 串口数据位可选 5/6/7/8，校验位可选无/奇/偶，停止位可选 1/2，流控可选无、软件 XON/XOFF 或硬件 RTS/CTS。默认保持 115200、8N1、无流控，终端、任务运行和连接测试统一使用保存的设置。
- 修改端口或波特率时保留其他串口参数，保存后重新打开设备设置仍保持完整配置。

## 界面调整

- 移除串口终端顶部的独占与关闭行为提示，以及设备设置中的串口说明和默认设备说明，精简操作界面。

## 验证范围

- Windows 本地 `npm test`：448 项前端测试通过。
- `cargo test --offline --all-targets`：317 项通过，20 项需外部环境的测试按默认规则跳过；覆盖旧串口配置默认值、自定义参数保存与重新加载、非法参数校验、驱动参数映射、串口 duplex 模拟及本机 SSH/SFTP 集成。
- `npm run build`、`cargo fmt --all -- --check` 和 `git diff --check` 通过。
- 使用模拟设备接口检查常用波特率选择、自定义数值输入、7E2 与硬件流控保存、修改端口和波特率后其他参数保留、重新打开设置及多余提示移除。
- 未执行物理串口、真实远程 SSH、WSL 发行版、USB、Windows 安装升级及 Linux/macOS 桌面实测。

## 升级说明

- Windows 安装版可使用应用内更新，包括此前发布的 0.24.0 安装版。
- 便携版下载 `Remote.Runner_0.24.1_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 设备配置无需迁移；旧串口配置缺少新增字段时沿用 8N1、无流控默认值。
