# Remote Runner v0.18.0

相对 v0.17.0，本版本集中改进键盘操作、编辑器标签、终端和运行历史管理。

## 新功能

- 新增应用操作快捷键：打开本机/设备工作区、保存全部、运行脚本、带参数运行、原配置重跑、停止任务、新建默认设备终端、聚焦编辑器/控制台以及切换侧栏。菜单和按钮展示对应提示，“帮助 → 快捷键一览”列出中英文操作说明和生效区域。
- 编辑器文件标签新增右键菜单，可关闭当前、其他、左侧、右侧、已保存或全部文件。批量关闭逐个处理未保存修改；取消或保存失败时保留整批标签。
- 运行历史支持清空当前工作区或全部历史，单条删除和批量清空均可通过事件列表撤销。删除信息及输出日志会保留，重启后仍能撤销；进行中的任务不能删除。
- 独立终端标签跟随 Shell 提供的标题更新；无标题时显示设备名，重连后清除旧会话标题。
- 预置命令名称改为可选；未填写名称时直接显示命令内容，新增或编辑时默认聚焦命令输入框。
- 菜单按文件、设备、运行、视图、设置和帮助分组，集中提供保存全部、运行控制和区域聚焦入口。

## 修复

- 应用快捷键按焦点和区域分发，保留终端原有的 Ctrl+C/D/Z/L/R/S/W/B/O、复制粘贴、导航键及 F5 等 Shell/TUI 按键，仅接管明确约定的标签切换、区域聚焦、新建终端和界面缩放组合键。
- 弹框、普通表单和输入法组词期间不触发后台操作；运行等操作忽略长按重复事件。同一任务的停止请求避免并发重复，不同任务可独立停止；终端连接期间仍可继续新建其他标签。
- 原配置重跑明确使用历史任务的原设备，不跟随当前目标选择；文件树运行以聚焦的脚本为准，不误用编辑器中的其他文件。
- 修正快捷键一览首次打开时的滚动和焦点位置，历史详情弹框不显示在该区域不可用的重跑快捷键提示。
- 发布流程在安装包、便携版和更新清单全部上传并校验通过后，自动公开版本并设为 Latest。

## 文档与维护

- 同步更新菜单归属、快捷键作用范围、编辑器批量关闭、终端标题和运行历史撤销说明。

## 验证范围

- 发布前代码复查通过：前端 280 项测试全部通过；TypeScript 检查、Vite 生产构建、Rust 格式检查及差异空白检查通过。
- Rust 离线全目标测试通过：290 项通过，20 项 WSL opt-in 测试按默认跳过，包含真实本机 Shell、串口模拟和本机 SSH/SFTP 集成等验证。
- 快捷键回归覆盖完整捕获分发链路、终端常用 Ctrl 组合键、复制粘贴、导航键、F1–F12、输入法和弹框保护、长按防重复、缩放/标签切换单次消费、目标记录定位及并发终端连接。
- 浏览器预览检查了菜单提示、快捷键一览、侧栏切换、控制台聚焦和终端按键不触发应用操作；预览不等于原生设备实测。
- 未执行原生安装/升级人工验收、外部 SSH 设备、物理串口、真实 WSL、USB 或其他桌面平台验证。
- Windows 安装包、便携版、更新签名与清单由 GitHub Actions 构建并校验，结果以本版本 Release 工作流为准。

## 升级说明

- Windows 安装版可在本版本正式公开后通过应用内更新升级。
- 便携版下载 `Remote.Runner_0.18.0_x64-portable.exe`，手动替换程序。
- `latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 相对 v0.17.0，无需手动迁移设备、工作区或 Python 项目环境。新增快捷键仅在应用窗口内生效，不注册系统热键；macOS 常规操作使用 Cmd，Ctrl+F5 与 Ctrl+Tab 仍使用 Control。
- 历史删除现在保留可撤销标记及日志。旧版本不理解这些标记，回退前请备份应用配置目录中的 `history.json` 和 `run_logs/`；回退旧版本可能重新显示已删除记录。
