# DevPort v1.4.0

## 新功能

- 「设置 → 强调色」新增默认、蓝、绿、黄、粉、橙、紫和黑八种预设。选择预设后，按钮、选区、焦点边框和已打开终端的光标会立即更新。
- 自定义配色支持取色器和六位十六进制颜色值。配色独立保存，可以与浅色、深色及跟随系统搭配使用。
- 强调色会根据当前明暗模式调整文字和控件的对比度。选择「默认」可恢复当前模式的原有配色。

## 验证范围

- 505 项前端测试及 TypeScript 和 Vite 生产构建通过，覆盖配色存储恢复、输入校验和浅深色对比度。
- 使用 Edge 和模拟设备验证键盘切换、取色器、重载恢复、终端输出保留和 200% 缩放。实体设备和 Linux/macOS 原生打包留待实测。
- Windows 安装版、便携版、安装升级流程、签名及两套更新清单由发布工作流校验。

## 升级说明

- Windows 安装版可使用应用内更新。便携版下载 `DevPort_1.4.0_x64-portable.exe`。
- 原有主题模式偏好继续生效，强调色初始使用「默认」。
- `latest.json`、`devport-latest.json` 和 `.exe.sig` 供应用内更新校验使用。
