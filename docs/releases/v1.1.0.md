# DevPort v1.1.0

## 新功能

- Windows 安装版在资源管理器的文件夹和目录空白处右键菜单增加“使用 DevPort 打开”，可直接将所选目录打开为本地工作区。Windows 11 入口位于“显示更多选项”，非中文系统显示“Open with DevPort”。
- 应用已运行时复用现有窗口；首次启动先恢复工作环境，再处理打开请求。有未保存修改时沿用保存、丢弃、取消流程，重复打开当前工作区保留已有标签。
- 支持 `devport.exe --open-workspace <directory>`，正确处理空格、中文、相对路径与盘符根目录；忙碌期间保留待处理请求。
- 安装和升级时更新目录菜单指向，卸载时只清除仍属于该安装的条目，保留被其他安装接管的菜单。

## 修复

- 移除终端标签上的序号及相关提示中的编号，保留终端名称、连接状态和关闭按钮。

## 验证范围

- 前端 475 项测试、TypeScript 与 Vite 构建通过，覆盖首次启动、工作环境恢复、未保存确认、取消、重复打开及忙碌期间的请求处理。
- Rust 全目标 327 项测试通过，20 项环境相关测试按默认设置跳过；覆盖目录类型、路径参数及 Windows 根目录校验，格式与差异检查通过。
- Windows 隔离 NSIS 安装器验收通过，覆盖旧版升级、菜单命令和图标、重复安装、升级卸载、正常卸载及菜单归属保护；测试使用独立注册表命名空间。
- 正式安装包由 CI 构建和签名，并在公开前再次执行隔离安装器验收及两套更新清单校验。
- 未执行资源管理器真实右键点击的桌面端到端验收、外部 SSH 设备、物理串口、USB 及 Linux/macOS 原生打包验证。

## 升级说明

- Windows 安装版可使用应用内更新；安装或升级后注册目录右键菜单。
- 便携版下载 `DevPort_1.1.0_x64-portable.exe`。便携版支持打开目录的启动参数，不自动注册系统右键菜单。
- `latest.json`、`devport-latest.json` 与 `.exe.sig` 用于更新校验，不应单独运行。
- 本次没有配置格式变更；继续保留 DevPort 1.0 的旧版数据迁移、原始数据备份与更新兼容机制。
