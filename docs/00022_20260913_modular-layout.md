# 00022 模块化布局：统一 Dock / Panel 架构

日期：2026-09-13
状态：已实现

## 背景

00008 建立的布局中，侧栏面板（Workspace / Commands / History）的显隐与折叠是
`LayoutState` 里写死的 6 个布尔字段，中间区是「编辑区（flex: 1）+ 控制台 footer
（固定像素高）」的层级结构，标题栏的切换按钮也是逐一手写的。新增面板需要改动
布局状态、App 渲染、菜单、标题栏、i18n 多个位置。

## 目标

1. 界面全部模块化：左 / 中 / 右三个槽位统一抽象为 **dock**，功能模块统一抽象为
   **panel**，共享注册表机制，不设置「主模块」。
2. 中间 dock 内文件编辑区与控制面板区是平等结构：都按注册表条目渲染、都可独立
   显隐 / 折叠、高度按比例分配。
3. 中间区允许全部隐藏（宽度让给其他 dock），不强制至少保留一个。
4. 标题栏的中间区切换按钮按支持手动显隐的注册表条目动态生成，位于最小化按钮左侧。
5. 新增面板只需在注册表加一项并关联组件。

## 设计

### 面板注册表（`src/panels/registry.tsx`）

```ts
interface PanelDef {
  id: "workspace" | "commands" | "history" | "editor" | "console";
  dock: "sidebar" | "center";   // sidebar 由 sidebarPosition 决定占据左/右槽位
  titleKey: string;             // 菜单 / 面板标题 i18n key
  manualVisibility?: boolean;   // 默认 true；false 时不生成菜单项和标题栏显隐按钮
  toggleKey?: string;           // 标题栏切换按钮 i18n key（center 面板）
  icon?: ReactNode;             // 标题栏切换按钮图标（center 面板）
  defaultVisible: boolean;
}
```

- 数组顺序即侧栏堆叠顺序与标题栏按钮顺序。
- 本文件只含元数据；组件映射在 `src/panels/components.ts`（`PANEL_COMPONENTS`），
  全部 `React.lazy` 加载，避免 registry → 组件 → store → layoutState 的模块循环。
- 组件 props 统一为 `{ visible, collapsed, onToggleCollapse }`。

### 布局状态（`src/layoutState.ts`）

```ts
interface LayoutState {
  panelVisible: Record<PanelId, boolean>;    // 取代原 6 个写死布尔字段
  panelCollapsed: Record<PanelId, boolean>;
  sidebarWidth: number;
  sidebarPosition: "left" | "right";
  sidebarVisible: boolean;                   // 侧栏 dock 整体显隐
  splits: Record<DockId, number>;            // 取代 sideSplit / consoleHeight
}
```

- `normalizeLayout` 以注册表为合法 id 来源：未知 id 丢弃、缺失 id 回落
  `defaultVisible`；持久化 key 保持 `remote-runner.layout.v1`，读取时迁移旧字段
  （`workspaceVisible` 等顶层布尔与 `sideSplit`）。v1 的 `consoleHeight`（像素）
  无法无损换算为比例，回落默认值 0.6。
- `panelVisibilityPatch` / `panelCollapsePatch` 生成单面板 setLayout patch。
- 不再有「至少保留一个中间区可见」的守卫。

### Dock 渲染（`src/App.tsx`）

- 侧栏 dock：按注册表顺序堆叠可见面板；高度分配沿用既有语义 —— Workspace 与
  History 同时展开时按 `splits.sidebar` 分比例（分割条位于 History 之前），预置
  命令面板不参与比例分配。`sidebarVisible` 或全部侧栏面板隐藏时整个 dock 不渲染。
- 中间 dock：编辑区 / 控制面板区两个平等 section，同时展开时按 `splits.center`
  分比例（SplitHandle 拖拽 / 双击重置）；dock 与 section 的隐藏用 `hidden` 属性
  而非卸载，CodeMirror 与 xterm 实例保持存活。两区全隐藏时 dock 隐藏，侧栏占满
  全部宽度。
- 打开 / 激活文件时若编辑区隐藏或折叠，自动恢复可见并展开（store `revealEditor`）。
- 编辑区默认隐藏；文件标签不持久化，启动时也会覆盖上次保存的编辑区可见状态。
  关闭最后一个文件、删除文件使标签清空、成功切换工作区时自动隐藏编辑区；
  取消关闭或保存失败时保留面板。编辑区不提供标题栏和视图菜单的手动显隐入口，
  面板内的折叠 / 展开按钮保留。

### 标题栏与菜单

- 标题栏在最小化按钮左侧按注册表顺序渲染支持手动显隐的 center 面板切换按钮
  （控制面板区、文件传输区），`aria-pressed` 绑定 `panelVisible[id]`；侧栏左 / 右整体切换按钮
  保持不变。
- 「视图」菜单的面板勾选项按注册表分组生成，跳过 `manualVisibility: false` 的面板；
  勾选侧栏面板时顺带保证侧栏 dock 可见。

## 行为变化

- 控制台区由固定像素高度（`consoleHeight`）改为与编辑区按比例分配
  （`splits.center`），窗口缩放时两区按比例伸缩。
- 编辑区首次支持整体隐藏（此前只支持折叠）。
- 中间区两区可同时隐藏。
