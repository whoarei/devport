# 00007 客户端状态与恢复

基线：2026-10-20 / 0.12.0。架构摘要见 [技术方案](00002-architecture.html#frontend)。

## 1. 前端职责与面板

React 18 + TypeScript，Zustand 管理状态，CodeMirror 6 编辑文本，xterm.js 渲染原始终端字节。组件调用 store 动作，纯逻辑模块处理可测试的归一化/转换；`api.ts` 和 `transferApi.ts` 分别封装主要 IPC 与传输域 IPC。安全校验在 Rust 再执行。

| 状态域 | 入口 |
| --- | --- |
| 设备、工作区、编辑标签、运行状态与布局 | `store.ts` |
| 工作区运行设置、命令、准备任务和实际启动摘要 | `workspaceRunStore.ts` |
| 运行历史查看、配置草稿与快照重跑 | `runHistoryStore.ts`；展示与转换见 `runHistory.ts` |
| 独立终端标签及连接 | `terminalStore.ts` |
| 文件传输计划/任务/浏览 | `transferStore.ts` |
| USB 设备与操作 | `usbStore.ts` |
| 工作环境快照编排 | `workEnvironment.ts`；窗口由 `windowState.ts` 约束 |

面板由 `panels/registry.tsx` 元数据和 `panels/components.ts` 懒加载映射注册，避免组件与布局模块循环依赖。侧栏为 Workspace / Commands / Runtime / History，中心为 Editor / Console / Transfer；Runtime 和 Transfer 默认隐藏，编辑器随文件打开出现。历史命令位于侧栏底部，默认高 260px，可拖动调整，保存范围 120–600px；旧布局缺失该面板时默认显示。侧栏左右切换、宽度、面板显隐/折叠和中心分割比例归一化后持久化。隐藏/折叠保持需要保活的编辑器、终端实例。

应用菜单按“文件、设备、运行、视图、设置、帮助”排列。一级菜单按使用场景划分，相关操作用分隔线分组；面板、设备列表和枚举偏好使用一层子菜单，避免顶级下拉菜单随功能增长不断变长。

| 菜单 | 内容（分号表示分组） |
| --- | --- |
| 文件 | 打开本机工作区、打开设备工作区、最近的工作区、关闭工作区；保存文件、保存全部文件、关闭文件；退出 |
| 设备 | 管理设备（新增、编辑、删除与排序）；文件传输、浏览设备文件；USB 共享 |
| 运行 | 运行当前脚本、带参数运行当前脚本；按原配置重新运行、停止所选任务（当前运行页可见时） |
| 视图 | 面板子菜单、侧栏显隐、聚焦编辑器、控制面板区显隐、新建默认设备终端、侧栏位置；放大、缩小、重置缩放；重置布局 |
| 设置 | 语言、主题；Ctrl+Tab 切换顺序；终端 Ctrl+C 复制选区、Ctrl+V 粘贴、选中即复制；开机自启动 |
| 帮助 | 快捷键一览、检查更新、关于 Remote Runner |

“视图 → 面板”继续从注册表生成，侧栏面板与中心面板分组；编辑器不提供手动显隐项。显示侧栏面板会同时显示侧栏。“设备 → 文件传输”保留面板显隐勾选和首次打开时的目录初始化；“浏览设备文件”只列出 SSH / WSL 设备，无适用设备时禁用。USB 共享仍限 Windows 桌面，开机自启动、退出和更新仍要求 Tauri 环境。子菜单支持悬停、点击和聚焦后按 Enter 打开，Escape 关闭整组菜单。

历史命令每次运行一条，统一展示全部工作区记录，不提供工作区筛选，进行中的任务置顶。准备/重建任务不进入脚本运行列表。没有记录时隐藏整个历史命令区域（含标题、占位及分隔条），不显示空白提示；产生记录或撤销恢复后，按原面板显隐与折叠偏好重新显示。隐藏是内容条件，不改写布局偏好，也不占用侧栏高度。控制台移除任务下拉框，固定展示最后一次运行的任务、状态、输出、停止和重新启动；没有当前任务时隐藏任务名称、状态、停止和重新启动所在的整行，保留设备、Python 和运行设置，有任务后显示并在任务结束后保留。历史详情使用独立对话框，不修改控制台任务。

记录右侧 `▶` 按保存配置在原设备重跑，`▾` 只有“当前设备重跑”和“编辑后运行”；两处重跑均生成新任务。当前设备模式只替换目标，保留字面参数、Python 环境模式、cwd、附加 env、控制台模式和超时，终端大小使用当前值。原设备配置修订或源设备修订变化、设备删除时进入编辑窗口，不回退到当前设备。跨工作区先走现有未保存修改与工作区切换流程；提交前后核对工作区 generation 和设备修订，Rust 再验证目标/源修订和所有输入。运行使用当前源码与项目依赖文件，不恢复源码快照。

单击记录查看详情和最多 2 MiB 的保存输出，运行中可停止；每秒有界刷新输出，不接管旧任务的交互输入。记录悬停或键盘聚焦 400ms 后预览完整入口、参数、工作区、目标、环境、cwd、模式、超时和结果，附加变量只显示数量。移开、Escape、滚动、失焦、隐藏或折叠关闭预览；浮层通过 portal 避免侧栏裁切，视口边缘翻转和约束。变量值需在详情中主动展开。

历史面板标题、空白处和记录的右键菜单统一提供“清空历史命令”，清空全部工作区的已完成记录；记录菜单另有单条删除。删除和清空均直接执行，跳过进行中的任务，不弹确认框。Rust 根据运行 ID 查找原始记录，拒绝包含活跃任务的请求，单次批量操作整体提交。移除的记录在 `history.json` 中保存删除批次和时间，记录与输出日志自删除起保留 7 天供撤销；成功后应用事件仅显示移除数量、时间和“撤销”，重启时重建未到期事件。恢复保留原 ID、运行配置、顺序和日志，不改变仍有效的当前控制台任务。历史容量仍为 200 条；恢复会超出上限时保留原批次和日志，事件提示先清理部分历史，可在 7 天期限内再次撤销。

后端启动时及运行期间每分钟清理到期记录和日志，隐藏到托盘后仍会执行；应用关闭期间到期的内容在下次启动时清理。按持久化的原始删除时间计算满 7 天，重启不延长期限，后端拒绝到期批次的撤销。前端每分钟刷新删除批次，移除已清理的撤销事件，保留其他事件及未到期动作的错误信息。写入采用同目录临时文件、`sync_all` 和原子替换，失败不修改内存或删除日志，下次重试；先提交到期记录移除再清理日志，删除文件失败时在后续清理中重试。孤儿日志扫描同时保护历史记录和活跃任务的日志。前端抑制已移除 ID 的迟到状态、输出和快照，避免记录重新出现。

应用入口在 `document` 的捕获阶段统一阻止 `contextmenu` 默认行为，禁用 WebView 自带的返回、刷新、另存为、打印等右键菜单；文件树、控制台等区域仍通过事件处理器打开自定义菜单。未定义菜单的区域（含输入框和面板操作按钮）右键不弹菜单，文本编辑快捷键保持可用。

“带参数运行”和历史任务的“编辑后运行”共用多行参数编辑器，每行作为一个原始参数；保留首尾空格及引号，忽略完全为空的行，纯空格行仍会传入。换行兼容 LF、CRLF 和 CR，不解析 Shell 引号或展开表达式。参数预览默认折叠，每次打开窗口时重新折叠。弹窗内 `Ctrl+Enter` 与运行按钮共用校验和提交路径；普通 Enter 换行，输入法组词和按键重复不会触发运行。直接重跑历史记录继续使用保存的参数数组，不经过文本框解析。

### 应用操作快捷键

`shortcuts.ts` 定义固定绑定、显示文案格式与作用区域；`appShortcuts.ts` 根据真实焦点识别文件树条目、编辑器、运行页、历史记录和 xterm 输入区。应用入口在 window 捕获阶段分发一次，菜单/按钮/快捷键共用 `appCommands.ts` 的可用条件和已有保存、运行、历史重跑路径。`commandUiStore.ts` 只保存一次性面板聚焦请求和快捷键一览的开关，不落盘。菜单右侧、运行/停止/重跑/新建终端等按钮提示和“帮助 → 快捷键一览”展示绑定，中英文同步。

| Windows / Linux | 操作与范围 |
| --- | --- |
| Ctrl+O / Ctrl+Shift+O | 打开本机 / 设备工作区；终端输入区之外 |
| Ctrl+S / Ctrl+Shift+S | 保存当前 / 全部文件；文件树或文件编辑区 |
| Ctrl+W | 关闭当前文件；文件编辑区，保留未保存确认 |
| F5 / Alt+F5 | 运行 / 带参数运行；编辑器当前 `.py` / `.sh` 文件或文件树聚焦的脚本，目录不回退到编辑器文件 |
| Ctrl+F5 / Shift+F5 | 原配置重跑 / 停止；运行页工具栏当前任务或键盘聚焦的具体历史记录，历史区空白处不使用旧选中项 |
| Ctrl+Shift+T | 新建默认设备终端；遵守无设备、默认设备为 Serial、8 标签上限、退出/更新限制 |
| Ctrl+` | 显示 / 隐藏控制面板区；隐藏或折叠时显示、展开并聚焦当前运行页 / 终端，已展开时隐藏；终端中也生效 |
| Ctrl+1 | 显示、展开并聚焦文件编辑区；没有文件时不打开空编辑器 |
| Ctrl+B | 显示 / 隐藏侧栏；终端输入区之外 |
| Ctrl+Tab / Ctrl+Shift+Tab | 焦点在文件编辑区时循环切换文件；其他区域循环切换运行页/终端标签；Shift 反向 |
| Ctrl++ / Ctrl+- / Ctrl+0 | 保留已有界面放大 / 缩小 / 重置 |

macOS 常规操作使用 Cmd，Alt 显示为 Option；Ctrl+F5 和 Ctrl+Tab 仍为 Control。快捷键仅在应用窗口内生效，不注册系统热键。不占用编辑器 Ctrl+Enter 的插入空行语义。

文件标签和运行页/终端标签共用“设置 → Ctrl+Tab 切换顺序”的左右顺序或最近使用偏好，各自维护独立的最近使用记录。按住 Ctrl 连续切换时冻结该区域的 MRU 顺序，松开 Ctrl 或窗口失焦后只提交最终标签。编辑区切换后焦点跟随正文，保留未保存内容、撤销栈和视图，惰性恢复的文件按原路径读取；没有文件或只有一个文件时不切到终端。跨区域使用 Ctrl+1 聚焦编辑区、Ctrl+` 切换控制面板区显隐。

控制面板区显隐快捷键、标题栏按钮和视图菜单共用同一命令。显示时展开并聚焦当前运行页或终端标签；隐藏时保留当前标签、分割比例、终端连接和运行任务。隐藏前焦点在控制面板区内时，转回当前文件编辑器；没有打开的文件则显示、展开工作区和侧栏并聚焦工作区，不打开空编辑器。焦点原本在其他区域时保持原位。标题栏提示、菜单和快捷键一览统一说明“显示 / 隐藏控制面板区”。

弹框打开时不分发后台操作或标签切换，历史详情弹框的重跑按钮不显示在该区域不可用的快捷键提示；普通 input/textarea/select、编辑器搜索输入框及其他可编辑表单不触发新增操作；CodeMirror 正文保留保存/关闭/运行等绑定。输入法组词、229 键码、AltGraph 和已处理事件直接放行。新增操作忽略 key repeat；异步执行期间额外防重入，同一任务的停止请求合并，不同任务可分别停止，新建终端连接期间仍可继续新建其他标签；不适用区域或禁用状态下匹配的 F5 被消费，防止 WebView 意外刷新。

所有 xterm 输入区的应用快捷键只接管缩放/标签切换以及面板显隐/编辑区聚焦/新建终端组合键。Ctrl+D/Z/L/R/S/W/B/O、F5 系列继续交给终端程序，不触发应用保存、关闭、打开、运行、停止或侧栏操作。独立终端和运行控制台共用下述剪贴板偏好；Ctrl+C 发送中断时只发一次，键盘长按重复事件忽略，停止继续调用独立 stop 流程。原配置重跑明确使用原设备快照，不跟随当前设备选择。聚焦请求在面板显示与懒加载挂载后消费，保留当前控制台标签及编辑选区。

`zh.ts` 是翻译键源，`en.ts` 约束同键，组件用 `useTranslation()`，逻辑模块用 i18n 实例。语言 `zh / en / system`，默认 system；主题 `light / dark / system`，默认 dark；界面缩放 70%–200%，支持恢复 100%。

“设备 → 管理设备”统一打开双栏弹框：左侧列出所有未删除设备，支持点击切换、拖动手柄排序与上移/下移按钮，顶部提供“添加设备”；右侧编辑属性、测试连接、设置默认设备和删除。打开时优先编辑当前选中设备，再回退到首台；无设备时显示新增入口。新增设备保存后追加到末尾，保存属性后仍留在管理弹框中。属性草稿仅在本次弹框内保留，切换设备、新增、删除或关闭前，对未保存修改提供保存并继续、放弃修改和继续编辑；保存失败保留草稿。空白新增表单不算修改。

弹框保留双栏与原有选中样式，去掉重复的设备标题、说明和独立“完成”底栏；测试连接、保存状态和保存按钮合并在同一底栏，右上角关闭按钮及 Escape 仍走原有编辑保护。所有适用于当前连接方式的选项直接显示，不再折叠“更多设置”：工作区根目录、默认设备、USB 管理，以及本机 Shell 的路径和 profile 开关均可直接访问。名称行提供恢复自动命名和删除入口；较小窗口中属性区独立滚动，底栏操作保持可见。

排序在松手或点击上移/下移后单次保存，无位置变化不写入。前端只传全部活动设备 ID，Rust 在设备操作锁内读取最新 `devices.json`，验证 ID 唯一且与活动设备完整匹配，在保留已删除设备数组槽位、时间及完整配置的前提下重排活动槽位，使用既有临时文件、同步和原子替换写入。JSON 继续使用数组顺序，不增加排序字段；旧配置先归一默认设备再重排，防止排序改变默认设备。排序返回带修订的设备列表，前端保持当前选中设备并同步各菜单、下拉框；不提交右侧属性草稿，不影响运行任务和终端。提交期间禁止再次排序和属性操作，失败恢复已确认列表；设备增删恢复导致 ID 集合变化时拒绝提交并刷新，不自动重试旧排序。迟到的列表读取不能覆盖新确认的修改。

名称位于属性表单顶部；添加设备时仍默认聚焦连接参数：SSH 主机地址、串口、WSL 发行版或本机 Shell。切换连接方式时聚焦新方式对应的字段。四种方式自动命名分别为 `ssh-root@192.168.1.10:22`、`serial-COM8:115200`、`wsl-Ubuntu-24.04`（指定用户时 `wsl-root@Ubuntu-24.04`）和 `local-pwsh`；SSH IPv6 地址加方括号。关键字段未填写时名称为空，自动模式随连接参数更新，手动修改后停止覆盖；点击“恢复自动命名”或清空名称并离开输入框后恢复自动模式。已有设备默认保留保存的名称。测试连接和保存都使用当前最终名称，落盘仍为原有 `name` 字段。

全局预置命令的名称可选，命令内容必填；名称去除首尾空白后为空时，列表标题和删除确认直接显示命令内容，保存仍保留空名称，后续修改命令时显示随之更新。添加/编辑弹框打开时默认聚焦命令编辑框，输入过程中不抢回焦点。

管理设备弹框右侧的删除按钮沿用直接删除流程，不额外弹删除确认；有属性草稿时先处理未保存修改。设备为可恢复删除：`devices.json` 中保留完整配置并标记 `deleted_at`，活动列表和运行入口不再返回该设备。右上角通用事件按钮显示当前事件数量，点击展开带时间的列表；删除设备事件左侧显示标题和时间，右侧显示“撤销”，不再重复显示配置保留说明。事件不自动过期，重启后从删除记录重建。撤销恢复相同设备 ID 与连接配置，保留当前默认设备，活动列表为空时将恢复的设备设为默认。普通事件保留在本次会话，可按项移除；可恢复删除事件在撤销前保留。`eventStore.ts` 只管理事件文案与动作，`deviceActions.ts` 串行处理设备保存、排序、删除、恢复和列表刷新。失败时保留恢复入口并在事件中显示错误，不把刷新失败视为删除数据成功丢失。

## 2. 异步一致性与编辑保护

工作区/目录/配置/历史/环境查询均用 epoch、工作区身份和源设备连接修订排除过期响应。文件标签另有 generation，旧保存结果不能覆盖关闭后重开的标签。工作区连接变更但 ID/路径相同，也必须使旧菜单及回调失效。

CodeMirror 标签保留 content、savedContent、revision、EOL、BOM、语言和编辑视图。切换标签保留会话内撤销栈；关闭、删除、切换工作区及真退出处理保存/丢弃/取消。运行前保存全部脏文件，失败不继续启动。保存带 revision CAS，外部修改标记冲突，重载不能默默丢弃草稿。

编辑器提供 29 种语法模式及纯文本：Python、Shell、PowerShell、JavaScript / JSX、TypeScript / TSX、HTML、CSS、JSON、YAML、TOML、INI / Properties、XML、Markdown、C / C++、C#、Java、Go、Rust、Lua、Ruby、PHP、SQL、Dockerfile、CMake、Nginx、Diff / Patch。`editorLanguages.ts` 集中维护语言标识、扩展名、特殊文件名及默认缩进；识别只检查文件名，特殊名称优先于扩展名，支持 `Dockerfile.*`、`Containerfile`、`CMakeLists.txt`、`.bashrc`、`.gitconfig`、`Cargo.lock` 等，未知文件回退纯文本。状态栏可手动切换，选择随文件标签保存并在重启后恢复；Rust 快照校验使用对应白名单，前端契约测试防止两侧遗漏。语言选择不改变执行类型或运行入口。

`editorLanguageSupport.ts` 按需加载并缓存语法包；Markdown 代码围栏复用同一组语言描述，嵌入语言也按需加载。语言切换及组件卸载取消旧加载结果，重配置保留正文、选区和撤销历史。加载失败时保留可编辑正文、显示提示并允许重试。原生语法包提供结构折叠，旧版流式语法模式按缩进折叠；Go 默认使用 Tab，Python 等默认 4 空格，Web / 配置 / Shell 等默认 2 空格，既有正文不会自动重排。折叠通过行号旁按钮或 CodeMirror 的折叠快捷键操作。

基础补全合并语法包提供的关键词、片段或局部符号与当前文档词汇，输入时显示候选，也可用 `Ctrl+Space` 打开；方向键选择、Enter 接受、Esc 先关闭候选，再次 Esc 沿用离开编辑区的行为，Tab 保持缩进和片段导航。候选框和折叠占位符跟随主题，语言名、提示及新增无障碍文案支持中英切换。当前未接入 LSP，不提供跨文件语义跳转、项目级重命名或类型诊断。

文件树单击以斜体预览标签打开文件，同一编辑区最多一个预览；单击其他未打开文件时在原位置替换预览，已固定标签只激活、不降级为预览。双击文件树条目或预览标签、首次修改正文后固定打开，撤销或保存后仍保持固定。读取失败保留原预览，快速切换时只采纳最后一次选择；双击在读取完成前发生也按固定标签打开。右键“打开”、生成配置等明确打开操作使用固定标签；工作环境快照继续保存全部打开标签，重启恢复后均作为固定标签。

文件标签右键菜单提供关闭当前、其他、左侧、右侧、已保存及全部标签；批量项显示目标数量，无目标时禁用。右键不切换活动文件，相对范围以右键标签为基准；“已保存”指没有未保存修改的所有标签。加载、保存、启动、未保存确认或工作区变更期间禁用关闭。标签 ×、Ctrl+W 和右键菜单共用批量关闭入口，按标签顺序逐个确认脏文件，全部通过后一次移除；取消或保存失败则保留整批标签及草稿备份资格，已完成的保存保留。确认期间锁住编辑和标签切换；工作区、源设备连接修订或文档身份变化时中止旧操作。活动标签未关闭则保持不变，否则选原位置右侧首个保留标签，再回退到左侧；惰性恢复的邻居会读取正文，全部关闭则隐藏编辑器。菜单沿用公共右键菜单的视口避让、点击外部及 Esc 关闭行为。

文件未读回时不能把空占位内容当正文写回。目录只按需加载，重命名/删除联动子树和标签；不能宣称编辑器与所有外部进程、独立文件传输共享全局文件事务。

终端上限 8，会话输出环形缓冲 1 MiB，每次读取最多 64 KiB，输入 16 KiB。读泵等 xterm 消费完上一批再读，隐藏标签仍有界排空；状态更新检查 session ID 防止旧会话串台。焦点在编辑区之外时，Ctrl+Tab 切换运行页/终端标签，释放修饰键提交选择。

独立终端与运行控制台的右键菜单、快捷键及系统原生粘贴均在操作开始时聚焦当前终端，粘贴后可继续输入。异步剪贴板读取完成时不再改变焦点，用户已切到其他区域时不抢回；读取结果核对原终端会话或原运行任务，避免发送到已替换的会话或任务。

“设置 → 终端”提供两个默认开启、独立持久化的全局开关：

| 开关 | 开启 | 关闭 |
| --- | --- | --- |
| Ctrl+C 复制选区 | 有选区时复制并保留选区；无选区时发送一次中断 | 无论有无选区都向终端发送一次 Ctrl+C |
| Ctrl+V 粘贴 | 读取剪贴板纯文本，通过 xterm 粘贴 | Ctrl+V 交给终端程序，保留 Shell/TUI 原始按键用途 |

两个开关立即应用于所有已打开的独立终端和运行控制台，无需重连。Ctrl+Shift+C / Ctrl+Shift+V 始终复制/粘贴，空选区复制不改写剪贴板，也不发送中断；右键复制/粘贴和系统原生粘贴不受开关影响。复制/粘贴快捷键消费匹配事件并忽略长按重复，避免 WebView 或 xterm 重复处理。输入法组词、AltGraph、Alt/Meta 组合及其他按键继续放行。快捷键一览根据当前开关显示 Ctrl+C / Ctrl+V 的实际行为。

`terminalClipboard.ts` 统一两类视图的快捷键与右键复制/粘贴：通过 xterm 保留粘贴换行处理和 bracketed paste 模式；异步读取期间视图隐藏、卸载、连接失效或任务被替换后丢弃结果。未连接时仍能复制历史选区，但不读取或发送粘贴内容。剪贴板失败只显示对应错误，保留选区、连接状态及任务状态，后续成功可清除提示。

“设置 → 终端 → 终端选中即复制”是默认关闭的独立全局偏好，保存在 localStorage，立即应用于所有已打开的独立终端及运行控制台。开启后，鼠标左键完成文本选择并松开时复制一次原始纯文本并保留选区；支持拖动到视图外释放、双击选词、三击选行和矩形选择。拖动中不反复写剪贴板；空选区、右键/中键、滚动条、程序化全选与后台输出不触发。TUI 开启鼠标上报时保留应用鼠标行为，仅在 xterm 原有强制选择修饰键生效时允许自动复制。切换会话/任务、隐藏视图、关闭开关、鼠标取消或窗口失焦会中止未完成的选择复制，卸载清理监听。复制失败只提示剪贴板错误，保留选区和连接状态，下一次成功后清除提示。

SSH / WSL / Local 独立终端断开、退出或连接失败后，在原标签显示“按 Enter 重新连接”，保留按钮及右键重连入口。终端输入区有焦点时，普通 Enter 新建会话；输入法确认、修饰键、长按重复及粘贴中的换行不触发。连接、关闭、应用退出或更新期间不重复建立会话，触发重连的整次按键（含 keypress / 重复 / keyup）不发送给新 Shell。先排空旧会话的末尾输出，再允许重连；失败可再次按 Enter 重试。“运行”页的脚本任务仍通过“重新启动”重跑。

xterm 显示实例跟随标签保留，重连只替换后台 session，沿用当前设备配置和标签原始工作区起始目录。保留最多 3000 行滚动历史并添加新会话分隔线，退出旧备用屏幕、重置输入模式并将旧视口滚入历史，以便新 Shell 清屏后仍可回看之前的普通输出；不恢复旧进程、临时 env 或后续 cd。输出写入串行处理，OSC 标题及终端自动回复按正在解析的数据所属 session 归属，旧会话回调与尚未完成的剪贴板读取不得影响新会话。

终端标签跟随 Shell 输出的 OSC 0 / OSC 2 标题，由 xterm.js 的 `onTitleChange` 更新；未收到标题或标题为空白时回退到设备名。标签省去“终端”前缀：Windows 绝对 `.exe` 路径仅显示程序短名（如 `pwsh`），POSIX 常见 Shell 的绝对路径显示 Shell 名；`user@host:/path` 或 `user@host:~/path` 显示主机及目录末级，根目录 `/` 与主目录 `~` 保留。SSH / WSL 优先以配置的设备名标识目标，再追加压缩标题，其他自定义标题保持原意。标题文字最多 180px，超出省略，状态点、编号和关闭按钮不参与压缩；悬停及无障碍名称保留完整原始标题与设备名。OSC 是自由文本，展示压缩不改变终端目录状态。隐藏标签继续更新，标题回调检查 session ID，重连新会话时清除旧标题；标题仅在当前会话保留，不进入工作环境快照。

## 3. 持久化地图

应用配置目录使用 Tauri `app_config_dir`，Windows 通常为 `%APPDATA%/com.devrunner.remote-runner`，解析失败回退 `dirs::config_dir()/remote-runner`。WebView localStorage 是另一存储位置。

| 位置 | 内容与边界 |
| --- | --- |
| `devices.json` | 四种设备配置及可恢复删除记录（`deleted_at`）；密码当前明文保存，无系统钥匙串集成；写入为同目录临时文件同步后原子替换，进程内串行修改 |
| `known_hosts.json` | `host:port → SHA-256`；TOFU，变更/损坏拒绝；进程内锁防陈旧连接覆盖 |
| `workspace-client-id` | 持久 UUID，参与目标同步来源身份；换配置目录会形成新来源身份 |
| `history.json` | 最多 200 个可见完成任务及删除后保留 7 天的记录，含可选 replay 快照：原请求、工作区运行请求、目标/源修订、目标摘要和实际启动摘要；快照在暂存和 Shell 环境解析前捕获，只含显式 env，不含设备认证信息或完整 profile 环境。落盘失败不影响运行，损坏按空记录加载 |
| `run_logs/<run_id>.log` | 每任务原始输出开头最多 2 MiB，随可见历史淘汰、删除满 7 天及孤儿清理删除；启动及运行期间每分钟检查 |
| `transfers.json` / `transfer-journal/` | 传输结果与提交检查点；不包含文件正文/认证快照；恢复规则见 00006 |
| `work-environment.json` | 本机工作视图及脏草稿快照，version 1，详见下节 |
| `<config_dir>/runtime-v1` | Local 托管运行时；SSH/WSL 在目标 HOME 下另存，见 00005 |
| 源工作区 `.runner` | 共享 cwd 与历史命令；不保存客户端草稿/窗口状态，见 00004 |
| 目标工作区 `.sync` | 来源认领、成功清单/缓存、恢复日志、执行目录锁，见 00004 |

不要把所有文件写入都称为原子：设备配置、工作环境、运行历史、`.runner` 和传输提交分别实现安全替换。旧版本不识别设备的 `deleted_at` 或运行历史的 `history_deletion`，降级时会重新显示可恢复删除的设备和历史记录。

主要 localStorage 键：

| 键 | 归属 |
| --- | --- |
| `remote-runner.layout.v1` | 面板、侧栏与分割比例 |
| `remote-runner.recent-workspaces.v2` | 最近 10 个 WorkspaceRef；旧 v1 本机路径列表迁移后删除旧键 |
| `remote-runner.language.v1` / `.theme.v1` / `.ui-zoom.v1` | 语言、主题、缩放 |
| `remote-runner.copy-on-select.v1` | 独立终端和运行控制台共用的选中即复制开关，缺省关闭 |
| `remote-runner.copy-on-ctrl-c.v1` / `.paste-on-ctrl-v.v1` | 独立终端和运行控制台共用的 Ctrl+C 复制选区 / Ctrl+V 粘贴开关，缺省均开启 |
| `remote-runner.presets.v1` | 全局预置命令，最多 100 条；不等于工作区命令历史 |
| `remote-runner.transfer-directories.v1` | 本机及各设备上次成功打开的目录；不存勾选项 |
| `runner.settings.v1:<workspace-key>` | 目标、按设备 Python/Bash 选择、env、模式、超时；cwd 来自源 `.runner` |

偏好坏数据防御性回落，写入失败保留会话设置。客户端附加 env 会落在本机 WebView 偏好及运行快照中，不应描述为秘密保险箱。完成任务的 replay 足以在重启后按原配置重新提交；旧记录缺少 replay 时只允许查看已有输出，不能猜测目标或设置。源 `.runner/commands.json` 继续保存可共享的入口/参数索引，与本机每次运行的快照分开。准备弹框任务和长连接上下文仍只在当前会话保留。

## 4. 工作环境恢复范围

快照保存当前工作区，最近 10 个工作区各自的文件标签顺序、活动文件、语言、光标/选区、横纵滚动、展开目录和树滚动；脏标签保存完整草稿、保存前正文、revision、EOL、BOM。干净标签只保存描述，不缓存正文。

另存最多 8 个终端的标签 ID、设备 ID、打开时工作区和起始子目录、活动终端，以及窗口普通大小/位置/最大化、传输设备和隐藏/排除选项。主动关闭工作区记为 null，不靠最近列表擅自重开。

| 限额 | 值 |
| --- | --- |
| 工作区 | 10 |
| 每工作区标签 / 展开目录 | 各 256 |
| 草稿正文 / 保存前正文 | 分别 1 MiB |
| 快照整体 | 32 MiB |

500 ms 防抖，仅视图/草稿变化触发；串行写入防旧结果覆盖新记录。失焦/隐藏尽力刷新，真退出和安装更新前等待刷新。Rust 有界读取上限+1 字节，验证版本/路径/重复项/大小/窗口数值，以 UUID 同目录临时文件完整写入、`sync_all` 后原子替换；Unix 权限 0600。

损坏、不兼容、超限记录保留原样，恢复失败的本次启动不覆盖；保存失败保留上次好快照并提示，不能截断草稿。强杀时最后约 500 ms 尚未提交的改动可能丢失。

## 5. 恢复次序与冲突

先读取本机快照和设备，再恢复工作区及描述；用户启动期间主动操作优先，慢恢复响应不覆盖新状态。优先读取活动文件，其他标签在激活/保存时加载；展开目录从父到子，仅访问存在且可见路径，不扫描整树。

离线或文件丢失保留标签和草稿并允许重试。未读回干净文件只读，草稿不自动写源文件；源 revision 变化时保留旧 revision 和冲突，由保存 CAS 阻止覆盖。恢复光标按当前文本长度截断。跨启动不恢复 CodeMirror 撤销栈。

终端只恢复未连接标签，用户点击连接或聚焦终端后按 Enter，按当前设备配置新建 session；不复用旧 session ID，不重放命令，不恢复进程、临时 env 或 Shell 后续 cd。Serial 不支持独立终端。

运行控制台的选中任务、输出和进程不进入工作环境快照。文件传输只恢复选项/浏览目录及后端中断结果，不恢复选择、计划或自动启动任务。

窗口大小为逻辑像素，位置为物理像素；按当前显示器/DPI 限制并将失联显示器位置移回可用屏幕。不恢复最小化，`--minimized` 启动保持隐藏，不因恢复最大化弹窗。

## 6. 退出、托盘、单实例和更新

关闭窗口仅隐藏到托盘，不执行真退出流程；任务/传输继续。手动重启第二实例聚焦原窗口，带 `--minimized` 的第二实例静默退出。single-instance 插件在 `lib.rs` 首先注册；自启动通过系统启动项带 `--minimized`，不属于应用配置文件。

真退出统一经 `appLifecycle.requestQuit`：展示窗口 → 忙状态守卫 → 未保存确认 → 有活动传输则确认取消并等清理 → 刷新恢复快照 → 关闭全部终端 → 销毁窗口。终端退出清理导致的标签清空不写成用户关闭；用户主动关标签则从下次恢复移除。丢弃后取消退出会重新赋予草稿备份资格。退出不提供脱离客户端继续托管运行进程的服务保证。

安装更新前阻止活跃运行、传输及忙/脏状态；有活动终端时提示更新将关闭全部终端，取消则保留会话。确认后先刷新快照，再自动关闭全部终端并等待后端清理完成，关闭失败则停止更新。确认和清理期间禁止新建或重连终端；清理不移除下次恢复的终端标签。标题栏与关于对话框共用此流程。更新安全及 portable 回退见 [00008](00008-development-and-release.md)。

关于对话框分为品牌与版本、工作区/运行/传输能力、运行目标、软件更新和项目链接。更新区区分检查、可用更新、手动下载、进度与失败状态，更新说明可展开查看；安装前明确提示将重启，安装进行中仍禁止关闭对话框。布局随中英文、主题和界面缩放调整，窄视口下能力介绍改为单列。`tests/about-browser.html` 使用模拟接口验收这些状态，不访问更新服务或实际安装。

## 7. 验证和数据管理

重点回归：旧响应失效、外部冲突、未读回文件保存、坏快照保护、串行写、启动用户操作优先、丢弃/取消、终端重连、显示器/DPI 计算。浏览器样例能验证布局和模拟恢复，不代替原生多显示器、系统托盘和自启动实测。

当前没有统一数据重置入口。需要人工清理时先结束任务并备份：清理应用配置会移除设备/信任/草稿及同步客户端身份，清 WebView 会重置偏好，远端工作区/运行时及操作系统自启动项另行管理。不能因清本机数据就声称远端目录或 USB 共享已撤销。
