PRODUCT SPECIFICATION

同一工作区，
在合适的设备上运行。

将脚本编辑、环境选择、跨设备执行与结果观察放进一个桌面工作台。用户关注入口、参数与执行结果，工具负责连接、准备和过程控制。

产品需求与交互基线源码核验 · 0.12.0更新于 2026-10-20

01 / POSITIONING定位、用户与需求

Remote Runner 面向需要反复在不同运行环境中执行 Python、Bash 或 Shell 命令的开发者和测试人员。目标可以是 Linux 服务器、开发板、虚拟机、可达的 SSH 设备、已登录 Shell 的串口设备、本机 WSL 或本机 Shell。

P01 · 开发调试

减少重复搬运与启动操作

编辑工作区后，选择设备与环境，直接运行脚本或模块；相同工作区再次执行时复用目标目录和已准备的依赖。

P02 · 测试与运维

让重复操作可复用、可观察

以逐项参数、工作区历史命令和全局预置命令执行任务，通过输出、状态、中断、停止和超时判断结果。

P03 · 多环境工作

分开选择源码位置与执行位置

本机或设备上的目录都可成为工作区；同设备直接运行，跨设备自动准备副本，用户始终能识别实际执行位置。

P04 · 连续工作

保留编辑上下文和未保存草稿

重新打开应用后恢复文件、视图和终端标签；离线或外部修改时保留草稿，给出重试或冲突处理入口。

当前产品以单用户桌面工作流为范围，不承担云端作业调度、团队权限、容器编排或脱离桌面客户端的常驻任务服务。Node.js 和其他程序可经预置命令调用，尚无专用托管运行时。

02 / CORE MODEL五个概念，贯穿整个工作流

概念用户理解关键规则
设备保存的一套连接与执行配置SSH / 串口 / WSL / Local；可测试、编辑、删除和设默认。
工作区正在编辑的源码目录本机或 SSH/WSL 设备目录；来源与运行目标独立。
工作区命令入口 + 逐项参数Python 脚本、Python 模块或 Bash 脚本；历史不绑定设备和环境。
运行设置这次在哪运行、如何运行目标、Python、cwd、附加环境变量、输出模式和超时；提交后不随 UI 变化。
任务 / 终端一次受控执行 / 一条交互 Shell 会话任务有生命周期和结果；独立终端用于自由交互，两者各自保留标签。

工作区历史记住入口和参数，重新使用时取当前设备、环境与设置。全局“预置命令”面板保存用户常用的 Shell 命令，采用独立的命令执行入口；它与工作区历史是两种不同复用方式。

03 / WORKBENCH工作台：按需出现，保留上下文

信息布局示意，不是交互原型。编辑器随文件打开出现；Runtime、文件传输默认隐藏。

应用菜单按操作对象分组：文件管理工作区与编辑文件，支持保存全部；设备提供配置管理、文件传输和 USB 共享；运行提供当前脚本运行、带参运行、原配置重跑和停止；视图管理面板、侧栏、焦点切换、新建默认终端与缩放；设置集中语言、主题、标签切换顺序和自启动；帮助提供快捷键一览、更新与关于。菜单与按钮显示快捷键提示；终端保留原有 Shell / TUI 按键，仅接管明确约定的标签切换、区域聚焦、新建终端和界面缩放。面板开关统一放在“视图 → 面板”子菜单，详细绑定及作用范围见 客户端状态与恢复。

工作区与文件

从文件菜单打开本机目录或设备目录，可从最近工作区返回。目录按展开加载，支持新建文件/目录、重命名和删除。本机工作区空白区及文件夹右键菜单可在系统文件管理器中打开对应目录。设备离线或访问失败时展示原因，不能把空列表冒充成功。

编辑与保存

CodeMirror 提供 Python、Shell、文本高亮与多标签；单个编辑文件最多 1 MiB。切换标签保留会话内编辑状态，支持关闭当前/其他/全部标签。焦点在编辑区时 Ctrl+Tab 切换文件，Ctrl+Shift+Tab 反向切换，与终端共用左右顺序或最近使用偏好；Ctrl+1 / Ctrl+` 可聚焦编辑区 / 控制台。保存保留换行及 BOM，并检测外部修改；关闭、删除、切换或退出有未保存内容时提供保存、丢弃、取消。

侧栏可调整左右位置、宽度、显隐及面板折叠；中心区域可调整分割。语言支持中文、英文和跟随系统；主题支持浅色、深色和跟随系统；界面缩放支持 70%–200%，可恢复 100%。

04 / PRIMARY JOURNEY从工作区发起一次运行

1 · 选择目标设备、Python 环境与运行设置
2 · 选择入口文件右键、模块、包或历史命令
3 · 保存并准备保存全部脏文件，准备执行副本及依赖
4 · 观察与控制实际启动摘要、输出、输入和最终结果

入口与参数

右键 .py 或 .sh 运行命中的文件，不依赖当前编辑标签。普通运行使用空参数；“带参数运行”逐项编辑，保留空参数、空格、引号和中文。Python 支持脚本、模块与可唯一推导名称且包含 __main__.py 的包入口。

历史命令可预览原始参数、编辑入口及全局删除单条记录。相同入口和参数合并，最多 200 条且总文件不超过 1 MiB；不提供批量清空。重命名无法确定模块新名称时，提示确认或编辑。

运行设置与重新运行

设置包含工作区内 cwd、附加环境变量、PTY/pipe 和超时（0 表示不限），以及适用时的 Bash 选择。Python 版本、依赖和源码搜索目录来自当前项目文件。重新运行沿用入口参数，取当前设置；当前工作区与原任务来源不同或来源未知时禁用。

提交一致性：先保存，再一次性取得目标与设置。保存期间切工作区或源连接会中止；提交完成后切设备只影响下一次运行。配置已变更时提示重新检查，不混用新旧设置。

源码与产物放在哪里

场景行为用户可观察的结果
本机工作区 → 本机原地执行产物直接写入源工作区。
设备工作区 → 同设备原地执行源码和产物留在该设备目录。
工作区 → 其他 SSH / WSL必要时先暂存，再增量同步固定 <根>/<工作区名>/workspace；展示路径和统计。
设备工作区 → 本机本机临时副本执行结束后清理副本及其产物，不自动写回来源。
工作区 → 串口每次完整上传文本独立运行目录；不提供通用下载。

SSH / WSL 同目录运行排队，等待可取消；不同来源的同名工作区提示冲突，要求调整名称或目标根。运行产生的额外文件保留，来源删除的受管文件可在安全检查后同步删除。

增量同步信任来源属性未变的成功清单，目标单独改动不会总被检测或修复；它不等于双向同步或版本化源码快照。详见 工作区与增量同步。

05 / EXECUTION FEEDBACK控制台与终端的交互

运行控制台展示最后一次任务、实际解释器/执行目录、准备阶段、同步统计、输出和结果；顶部保留设备、Python 和设置，没有当前任务时隐藏任务状态、停止及重新启动所在的整行，有任务后显示并保留运行结果。侧栏底部“历史命令”每次运行一条，统一显示全部工作区记录，无记录时自动隐藏整个区域，不显示筛选或空白提示。保存完整参数、目标设备和执行设置，支持原设备重跑、当前设备重跑及编辑后运行。悬停 400ms 预览配置，单击打开独立详情与日志；查看历史不改变控制台任务。自由 Shell 操作使用独立终端或预置命令。

动作预期反馈
查看任务准备、同步、启动、运行、停止及终态清楚可见；非零退出码可识别。
输入 / Ctrl+C运行中可交互；有选区时 Ctrl+C 复制，无选区只发送一次中断。程序可以捕获后继续。
停止 / 超时停止执行受控终止流程；超时报告原因。不能确认远端退出时明确提示未知状态。
窗口尺寸变化SSH / WSL / Local 可调整；Serial 只在启动时设置尺寸。
切任务 / 终端任务输出有界回看；独立终端最多 8 个，Ctrl+Tab 可切运行页与终端标签。断开后聚焦终端按 Enter 可在原标签新建连接，保留之前的滚动输出，失败后可重试；粘贴换行不会触发重连。终端标签精简 Windows 程序路径及 Linux 用户/主机/目录标题，SSH / WSL 保留设备名，自定义标题保留原意；无标题时显示设备名。长标题省略显示，悬停可查看完整原始标题及设备名。

PTY 适合终端交互，pipe 可分开接收 stdout/stderr；Serial 只有合并流。Windows Local pipe 的单次 Ctrl+C 不受支持，会报错并保持任务运行；可改用 PTY 或停止按钮。

输出窗口有容量限制，过快时可能丢弃旧数据并提示缺口；不是无限完整日志查看器。后端最多保留 200 条可见完成任务及配置快照，每任务磁盘日志最多 2 MiB，可在历史详情中查看并删除单条记录。删除或清空后保留 7 天供事件列表撤销，到期自动清理记录、日志和撤销事件；应用关闭期间到期的内容在下次启动时清理。重启不会恢复运行进程；新记录可按保存的配置再次执行，旧版本记录缺少配置时仅支持查看已有日志。重跑使用当前源码与依赖文件。

06 / PYTHON ENVIRONMENT默认 Python 与项目环境

DEVICE DEFAULT

使用目标已有环境

运行普通脚本或模块，无需完整 uv 项目。用户负责设备上的依赖，本机解析遵循所选 Shell 的 profile。

UV PROJECT

按项目锁准备依赖

读取 pyproject.toml、uv.lock、.python-version，自动部署固定 uv 与受管 CPython，创建并复用项目依赖环境。

项目环境支持 SSH、WSL、Local，串口不支持；失败不会静默切换到设备默认 Python。项目版本允许 3.12 或完整补丁版本，实际解析版本会显示和记录；需要完全固定补丁时在源文件明确指定。

运行设置中可重新检查、准备或重建，弹框内展示冻结的源工作区、目标、阶段、进度、近期日志与结果。关闭弹框不停止准备，重新打开可继续查看；取消可停止准备。Runtime 面板可查看运行时与项目实例、删除空闲实例及清理缓存。

只改源码通常复用依赖，改锁或版本则重新检查。重建成功后切换到新实例，已有运行继续使用原实例；活动环境不能删除。当前不提供任意已有 venv、requirements/Conda/Poetry 模式或完整离线安装 UI。详见 Python 运行环境。

07 / SUPPORTING WORKFLOWS文件传输与 USB 共享

本机 ↔ SSH / WSL 文件传输

在双栏浏览器选择源条目和目标目录，预检后以保留两份、跳过或覆盖策略开始。支持二进制、多选与递归目录，单文件 2 GiB、单批 10 GiB、10,000 条目；不套用运行上传的小文件限制。

队列显示进度、速度、部分成功和逐项结果，提供取消、失败项重试及残留清理。已提交文件在取消后保留；提交结果未知时显示“待核对”，须检查后重选。关闭面板继续传输，重启只恢复中断状态，不自动续传。没有暂停续传、设备间直接复制或自动下载运行产物。

Windows USB → WSL2 / 远程 Linux

通过“设备 → USB 共享…”检查依赖、选择目标并连接开发 USB，支持断开、取消共享和节点访问验证。Windows 需要默认位置安装的 usbipd-win 5.x；远程 Linux 还需 Python 3.8+、usbip、vhci_hcd 和 root/具体命令的免密 sudo。

共享与取消共享按需触发 UAC。连接后 Windows 无法同时使用该设备，WSL2 连接对虚拟机生效；任务结束或关闭应用不会自动断开。远程 USB 数据由 Linux 访问 Windows IPv4 TCP 3240，不经过 SSH，适用于可信网络/VPN。没有自动安装驱动、防火墙修改或自动重连。详见 文件传输与 USB。

08 / CONTINUITY恢复工作环境与桌面生命周期

恢复内容处理方式
工作区、文件标签、光标和目录树恢复描述，活动文件优先，其他文件按需读回；启动期间用户主动操作优先。
未保存草稿保留正文和原 revision；离线可重试，外部修改冲突不自动覆盖源文件。
终端标签恢复为未连接，点击连接或聚焦终端后按 Enter，按当前配置新建连接；不重放命令、不恢复进程。
窗口和传输选项恢复大小/位置/最大化并适配当前显示器；传输不恢复选择或自动开始。

快照最多 10 个工作区，每工作区 256 个标签/展开目录，草稿及保存前正文各 1 MiB，整体 32 MiB。超限或损坏明确提示，保留旧记录；约 500 ms 防抖尚未落盘的末尾编辑可能在强杀后丢失，不恢复跨启动撤销栈。

关闭窗口隐藏到托盘，任务和传输继续；真退出处理未保存文件、活动传输、快照刷新和终端清理。自启动静默驻留，手动第二次启动聚焦原窗口。Windows 安装版支持签名更新；portable、debug 或识别失败提供手动下载，活跃任务或传输期间阻止安装。有活动终端时先确认，再自动关闭全部终端，等待清理完成后安装；取消或关闭失败不安装。详见 客户端状态与恢复。

10 / ACCEPTANCE & EVOLUTION验收标准与后续演进

需求可检查的完成标准
P01 · 编辑与运行右键未打开文件可运行；原始 argv 保真；脏文件保存失败不启动；实际目标/解释器/cwd 可见。
P02 · 可复用与控制重复入口参数去重；历史使用当前设置；Ctrl+C 可被程序捕获后继续，停止/超时得到明确结果。
P03 · 多环境同设备原地、跨设备暂存、SSH/WSL 固定目录符合说明；同名来源冲突、目录排队、失败恢复不误删产物。
P04 · 连续工作重启恢复标签/草稿，外部冲突不覆盖；终端不自动重连；坏快照保留并可见；用户主动操作不被旧响应覆盖。
辅助能力传输部分成功/未知提交可区分；USB 逐次核对身份；活动任务阻止安装更新。

验收需区分自动化模拟、真实本机进程、显式 WSL 和硬件实测。普通套件不依赖物理串口或 USB；相关硬件能力需单独验证，见 开发、验证与发布。

后续优先围绕当前使用阻力评估：运行产物浏览与获取、可靠清理与锁恢复、真实目标兼容性、离线/镜像交付、更多运行时及 Serial Agent。它们是候选方向，没有在本方案中承诺版本或日期；新增需求先补产品行为，再补技术设计。
